# run33 — 지금의 활동자료 서식으로 대일기업 자료를 올려 보기

목적: 컨설턴트가 서식을 채워 주면 올려서 8단계까지 가는 흐름(메모: 서식의 목적)에서 지금 서식이 어디서 끊기는지 확인.
방법: `build-filled-template.mjs`로 run14 기준선 자료를 지금 서식(4시트)에 채움 → 빈 프로젝트의 `/upload`에 실제 파일 올리기(Playwright) → 지도·제출 화면 확인.

## 결과
| 확인 | 결과 |
|---|---|
| 올리기 | 11건 저장(제품 2 · 공정 2 · 배출원 5 · 구매 강재 2), 경고 없음 |
| 사업장·보고기간 | 서식에 칸이 없음 → 지도 1단계에서 손으로 입력. 올린 자료는 보고기간에 연결되지 않은 채 남는다(기간이 하나일 때는 그대로 계산·문서에 들어감) |
| 직접배출 | **막힘.** 올린 공정은 「템플릿 업로드」 방식(공정 시트의 직접배출 칸 = 0)이라 배출원 시트의 연료 5행이 계산에 들어가지 않는다 → 지도 4단계 「0 tCO₂e」, 기준 SEE 3.742(기준선 3.764). 앱이 「배출원 합계 71.729와 직접배출 0이 다릅니다」로 파일 만들기를 막는다(조용히 틀리지는 않음). 공정마다 산정방식을 손으로 바꿔야 풀린다 |
| 제품 생산라인 | 서식에 없음 → 스크랩·불량(활동수준 제외) 2줄이 사라짐 |
| 공용 계량기 정보 | 서식에 없음 → 나눈 연료가 보통 행으로 들어와 「공장 전체 값·나눈 근거」가 사라짐. 귀속 점검이 6개 → 4개로 줄고(V01 해당 없음), 보고서의 배분 근거 문장이 안 나온다 |
| 전력 공용 계량기 | 같음(공정별 값만) |
| 구매 강재 | 값은 들어옴. 제품별 귀속·검증 상세·전력 분해 칸은 서식에 없음 |

## 결론
지금 서식은 「올리면 8단계까지」가 아니다: 올린 뒤 ① 사업장 ② 보고기간 ③ 공정별 직접배출 산정방식 ④ 생산라인 ⑤ 공용 계량기 나누기를 앱에서 다시 입력해야 한다.

참고: 내장 브라우저는 스크립트로 파일을 올릴 수 없어 Playwright로 올렸다. Playwright 프로필에는 예전 시험 설정이 남아 있어 비교 막대의 기본값 조회는 이 시험에서 보지 않았다.

# 새 서식(v2)으로 다시 — 같은 날

목적이 「컨설턴트가 업체에서 채워 오고, 받은 사람이 올려서 8단계까지」이므로 서식을 새로 만들었다(`src/lib/activity-workbook.ts` · `activity-import.ts`).

## 실제 엑셀로 해 본 것
`make-workbooks.mjs make` → `excel-fill.ps1`(진짜 Excel이 빈 서식을 열어 사람이 치듯 74칸을 채우고 저장) → `make-workbooks.mjs read`(앱의 코드로 그 파일을 읽어 넣고 엔진 계산).

| 확인 | 결과 |
|---|---|
| Excel이 여는가 | 시트 7장 · 선택 목록 543칸 · 오류 셀 0 |
| 선택 목록 | 연료 종류 5개 · 공정/제품 이름은 앞 시트에 적은 대로 목록에 나타남(「공장 전체(공용)」 · STS 나사 공정 · 탄소강 나사 공정) |
| 날짜 | 보고기간 칸은 글자 서식이라 2025-01-01이 날짜로 바뀌지 않음 |
| Excel이 저장한 파일 읽기 | 사업장 22칸 · 제품 2 · 공정 2 · 연료 3 · 구매 강재 2 — 빠짐없이 읽힘 |
| 넣은 결과 | 사업장 1 · 보고기간 1 · 제품 2 · 공정 2 · 연료 3(공용 2개는 공정별 행으로 나뉨) · 구매 강재 2, 넣지 못한 것 0 |
| **SEE** | **기준 3.7637 · 총 5.1117** — 지도에서 손으로 넣은 기준선과 같다 |

## 브라우저(Playwright)로 올려 본 것
빈 프로젝트의 `/upload`에 Excel이 저장한 파일을 올림 → 「서식을 넣었습니다 — 사업장 1 · 보고기간 1 · 제품 2 · 공정 2 · 연료 3 …」 + 「확인할 것」 목록 → `/submit`이 바로 「보낼 수 있습니다. 다만 …」(파일 버튼 활성). 손으로 더 입력한 것 없음.
이 시험 프로필에는 예전 시험이 넣어 둔 1행짜리 가짜 기본값표가 있어 대만 원료의 EU 기본값을 못 찾았고, 앱은 그 줄을 「넣지 못함 — 5_구매강재 6번째 줄」로 알렸다(지어내지 않음). 진짜 기본값표로는 위 표처럼 들어간다.

## 종전 서식과의 차이 (run33 앞부분에서 끊기던 곳)
| 끊기던 곳 | 새 서식 |
|---|---|
| 사업장·보고기간 없음 | 1_사업장 시트에서 받아 만들고, 모든 자료를 그 기간에 연결 |
| 연료 시트가 계산에 안 들어감 | 배출원 합계 방식으로 맞춤(지도 4단계와 같다) |
| 공용 계량기 정보 없음 | 「공장 전체(공용)」 한 줄 → 앱의 「연료 나누기」·「전력 나누기」와 같은 기록 |
| 생산라인(불량·스크랩) 없음 | 공정 시트의 「불량·스크랩」 칸 → 활동수준 제외 라인. 같은 공정 이름을 여러 줄 쓰면 제품 라인 여럿 |
| 영어 코드 머리글 | 한글 머리글 · 칸마다 설명과 예시 · 선택 목록 · 안내 시트 · 작성 예시 파일 |
| 올린 뒤 무엇이 빠졌는지 모름 | 「확인할 것」: 시트·줄 번호 · 넣지 못함/확인 필요/참고 · 복사해서 돌려보내기 |
