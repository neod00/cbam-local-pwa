# 사용 일지 — run42: 외주 연료 + 외주 전기(간접배출) 입력 시험

- run: 2026-10-17_run42-outsourced-fuel-electricity · 앱 main `9b73455`(PR #164~#167 병합 직후) · 탐색 모드(새 기능 시험)
- **실제 업체가 아니다.** run41과 같은 전형 가상 업체(인천 소형 냉간압조 체결부품 공장, 품번 8·CN 6·강종 4, 구매 강재 5줄, 전력 1,350 MWh)에 **외주 전기 입력**(방금 병합한 기능)을 얹었다. 모든 수치는 가상.
- 목적: 외주 연료와 외주 전기를 한 외주처가 함께 쓰는 현실적 입력이 ① 서식 → 앱 → 화면 → 산정보고서·모니터링 계획·EU 엑셀로 끝까지 일관되게 가는지, ② 일부러 넣은 잘못된 줄을 앱이 올바르게 거절·표시하는지 본다.
- 방법: Excel로 서식 입력(247칸) → 앱 코드로 읽기 → 실제 앱(Chrome 원격조종)에 올리기 → 지도 4단계 화면 → 제출 문서 4종 내려받기 → EU 엑셀 Excel 전체 재계산.

- 전력: 1_사업장 1,350 MWh(공용 계량기 → 4공정 생산량 비율) + 외주 전기 131.13 MWh = 공정 합계 1,481.13 MWh. 외주 몫이 공정 전력(SCM435 385.43 · SWCH10A 927.08 · SWCH18A 145.64)에 얹혀 있고 공용 계량기 합계 검사는 「고지서와 같습니다」를 유지했다(자체 몫 합 1,350).
- SEE(앱): 직접은 run41과 똑같다(너트 2.6642 · 휠 볼트 4.5088 · 4.8 볼트 2.6671 · STS 5.9851 — 외주 전기는 간접만 바꾼다). 총 SEE(간접 포함)는 너트 2.9520 · 휠 볼트 4.8300 · 4.8 볼트 2.9965 · STS 6.2580. 인증서 기준(see_cbam_basis)은 직접+전구 직접.
- EU 엑셀(Excel 전체 재계산): 오류 셀 0. Summary_Products의 간접 SEE가 앱과 같다(예: SWCH10A 공정 0.28782 = 927.0843×0.475÷1,530).
- 귀속 점검 V10: 확인 필요 1줄(코팅 H사 분류 근거). 엔진 경고 0.
- 제출 화면: 「넣지 못한 줄 2건」(K사·L사)을 이유와 함께 보인다.

## 화면·문서에서 본 것
- 지도 4단계: 연료 패널의 안내가 아래 전기 패널로 안내. 전기 패널에 H·M·G 세 건이 공정 몫과 방법·근거로 나온다. M사는 「보수적 추정입니다」 점검이 붙는다.
- 산정보고서 6.6: 표에 「에너지」 열, 연료 3줄 + 전기 3줄. 마무리 문단이 연료·전기 각각의 반영 위치를 말하고 **연료만 입력한 J사에게만** 「전기가 입력되지 않았습니다」 안내가 붙는다.
- 모니터링 계획 9번: 외주처별로 연료·전기 줄이 따로 나오고, 통제 문장이 전력 자료를 포함한다. 같은 J사 안내가 있다.
