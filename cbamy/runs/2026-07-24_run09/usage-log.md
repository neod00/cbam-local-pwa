## 3. [핵심] MIXED 집계 상태 — 실사용 첫 확인

화면 출력:

```
CBAM 산정 기준      0.188 tCO₂e/t
간접 (제품마다 다름)  0.02  tCO₂e/t
총 SEE (검토용)     0.196 tCO₂e/t

제품마다 간접분의 인증서 기준 반영 여부가 달라, 기준 SEE와 총 SEE의 관계를
한 줄로 말할 수 없습니다 — 제품별 결과를 확인하세요.
```

손계산 대조 — **전부 일치**:

| 값 | 손계산 | 화면 |
|---|---|---|
| 직접 합계 | 598,891.9 tCO₂e | 598,891.9 |
| 간접 합계 | 68,910 tCO₂e | 68,910 |
| 기준 SEE | 0.188 | 0.188 |
| 간접 SEE | 0.020 | 0.02 |
| 총 SEE | 0.196 | 0.196 |

**그리고 결정적으로**: 기준(0.188) + 간접(0.020) = **0.209 ≠ 총(0.196)**.
MIXED에서 총 SEE 항등식을 인쇄했다면 **틀린 등식이 화면에 나갔을 자리**다.
앱은 인쇄하지 않았고, 대신 「한 줄로 말할 수 없습니다」라고 했다.

라벨도 「보고용」이 아니라 「제품마다 다름」이었다 — 간접분이 기준에서 빠진다고
단정하지 않는다. 소결광에서는 그 단정이 **거짓**이기 때문이다.

R7~R9 작업이 단위테스트 밖에서도 성립한다.
