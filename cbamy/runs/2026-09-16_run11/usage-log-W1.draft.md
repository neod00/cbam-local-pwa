## 3. 1단계 보고기간 — PASS (2025년 결정, 앱은 침묵)
- 지도로 돌아오니 1단계 문구가 "← 지금 여기 · 보고기간을 등록하세요"로 바뀌어 있어 다음에 뭘 할지 바로 알았다. 패널에 "사업장: 대일기업 안산공장 (KR) / 영문 Daeil Industrial Co., Ltd. Ansan Plant"가 표시됨.
- 보고기간 추가 버튼: "2026년 연간" / "상반기" / "하반기". "2026년 연간"을 눌러 보니 기간 이름 "2026년 연간", 시작 2026-01-01, 종료 2026-12-31이 자동으로 채워졌다.
- 결정(§8-1): 고객사는 "2026 확정기간 신고"라고 했지만 2026년은 아직 진행 중이라 연간 고지서가 없다. 내가 가진 건 2025년 1~12월 자료다. 세미나에서 "직전 연도 자료로 SEE를 낸다"고 들은 기억이 있어 2025-01-01~2025-12-31로 고쳐 넣었다. 앱이 2026을 요구하거나 "2025 자료를 써도 된다/안 된다"는 안내를 해 줄지 기대했는데, 저장하니 **아무 경고·안내 없이** "2025년 연간 2025-01-01 ~ 2025-12-31"로 등록됐다. 상단 배지는 여전히 "2026 Definitive Period". 이게 맞는지 확신이 없어서 고객사(또는 헬프데스크)에 "2025년 실적으로 SEE 내도 되나"를 질문 목록에 올린다.

## 4. 2단계 제품·CN — STS 나사 등록 PASS, 스크랩 판정 PASS, 탄소강 포함 결정
- 2단계 패널 문구: "EU로 수출하는 제품과 CN 코드를 연결합니다. CN이 대상 여부를 결정합니다." 입력 칸은 "제품 이름"(예: 아연도금 강선)과 "CN 코드 (8자리) — 수출 신고필증·인보이스의 HS 코드 8자리와 같습니다." 관세사가 준 수출신고필증 7318.15-5200과 같다는 걸 알고 있어서 73181552를 그대로 쳤다.
- 8자리를 다 치자 바로 판정이 떴다: "CBAM 대상 · Iron and steel — EU 공식 Communication Template(판본 20241213)의 CN 목록에서 CN 73181552 → 품목군 「Iron or steel products」로 조회됨." 고객사 메일의 코드가 대상이라는 걸 앱이 확인해 줘서 안심.
- 「제품 추가」 → 목록에 "STS 십자홈붙이 나사 … CN 73181552 / CBAM 대상 · Iron and steel", "제품을 저장했습니다. 더 추가하거나 다음으로 이동하세요. [다음 단계로]".
- 스크랩(§8-8): CN 칸에 7204를 쳐 보니 "CBAM 대상 아님 (스크랩·제외 페로알로이) — 고철·철스크랩(CN 7204)과 일부 페로알로이(CN 7202 46)는 EU 공식 Communication Template(판본 20241213)의 CN 목록에 없습니다. 전구물질로 넣지 마세요. 내재배출 0 취급의 확정기간 근거는 확인 필요(규정)." → 결정: 스크랩 355 t은 제품으로 등록하지 않는다. 3단계 공정 폼에 "불량·부산물·스크랩으로 나간 양 (t, 선택)" 칸이 따로 있었으니 거기에 적으면 될 것 같다. 다만 "확정기간 근거는 확인 필요(규정)"라는 꼬리표가 앱 스스로도 확신이 없다는 뜻으로 읽혀 조금 불안하다.
- 탄소강 나사 CN 73181558도 쳐 보니 똑같이 "CBAM 대상 · Iron and steel … 「Iron or steel products」로 조회됨". 
- 상세 화면(/products)에서 STS 나사 행: 상태 "산정 준비 / CBAM 신고 대상", 태그 "철강 앱 대상 / 직접배출 중심 계산 품목 / 원재료·중간재 배출자료 확인", 할 일 "공정 초안 필요 / 생산량 필요 / 매입 소재 확인 / 소재량 필요", 설명 "쉽게 말해 이 품목은 CBAM 인증서 산정 시 직접배출 중심으로 계산합니다. 최종제품 자체 간접배출은 참고용으로 별도 관리합니다." 「고급 규정 정보」를 펼치니 "Annex I: Annex I 후보 / 간접배출 관련성 (확정기간): 간접배출 비관련(확정기간) / Indirect emissions: 인증서 산정 제외 / Precursor: 전구물질 검토 권장".
  → 이해한 것: 우리 나사는 전기 배출이 고객사 인증서 계산에는 안 들어가고 "참고용"이다. 그래도 가이드에는 "입력 필수"라고 했으니 전력은 넣어야 한다. 공장장에게 "전기는 신고는 하되 돈에는 안 들어간다"고 설명하면 되겠다. 그런데 "Annex I 후보"라는 표현이 뭔지 모르겠다(후보? 확정이 아니라는 건가). 품목군 "HS73_OTHER"도 낯설다.
- 상세 화면 상단 카드: "품목 코드 등록 1/1 — CN 8자리 입력 완료", "CBAM 대상 가능 품목 1개", "직접배출 중심 계산 품목 1개 — 인증서 계산은 직접배출 중심", "원재료·중간재 확인 1개 — 공급망 SEE 자료 확인 필요". "EU 수출 품목 코드 목록 — 현재 검색 목록: 20개 / EU 템플릿에서 가져오기" 버튼이 있는데 우리 코드는 이미 조회됐으니 안 눌렀다. "제품 목록 붙여넣기"(엑셀 복사)도 있는데 제품 2개라 안 씀.
- 결정(§8-2 탄소강 포함 여부): 2단계 문구는 "EU로 수출하는 제품"이라 탄소강은 안 넣어도 되는 것처럼 읽힌다. 그런데 3단계 패널 도움말이 "여러 제품을 같은 라인에서 만들면 각각 적으세요 — 배출량이 생산량 비율로 자동 배분됩니다."였다. 우리 냉간압조·전조기는 STS·탄소강 공용이고 한전 계량기가 하나뿐이라, 탄소강을 안 넣으면 전력 5,412 MWh 전부가 STS 3,240 t에 얹힌다 — 그건 명백히 과다. 그래서 탄소강 나사도 "배분용"으로 등록하기로 했다(내가 지운 이전 데이터도 "EU 수출 없음 · 공용라인 배분용"이라 적혀 있었던 걸 보면 앞사람도 같은 결론이었던 듯). 나중에 EU 문서에 탄소강이 제품으로 딸려 나가면 그때 빼거나 표시할 방법을 찾는다.

## 5. 2단계 — 탄소강 나사 상세 등록 PASS, 템플릿 불일치 직접 수정
- /products 「품목 추가」 상세 폼: "제품군으로 시작 — 철강 가공사 기준 / 제품을 고르면 CN 후보를 먼저 좁힙니다 … 쇳물, 고로, 전기로, 제강, 주조·압연 전 과정을 직접 운영하는 제철소형 산정은 간단 모드 범위를 넘어섭니다." 제품군에서 "파스너·볼트·너트"를 고르니 세부제품 "볼트·너트·스크류·와셔"가 자동 선택되고 안내 "파스너·볼트·너트: 볼트, 너트, 스크류, 와셔, 리벳처럼 SKU가 많은 체결류 제품군입니다. 예: 서울금속, 풍강", "CN 7318 CBAM 대상 후보 검색목록 2개 / 예: 73181595, 73181699", "필요 자료: 제품별 생산량, 매입 선재·봉강 사용량, 전력 사용량, 열처리·표면처리 연료 사용량, 스크랩·수율" → 준비할 자료 목록이 우리 공장 상황과 정확히 맞아서 좋았다.
- HS 코드 "7318", HS 그룹 "HS 73 (철강 제품)", 제품군 템플릿 "HS73_FASTENER"가 자동으로 채워졌다. CN 8자리 칸에 73181558 → "CBAM 대상 · Iron and steel / … CN 73181558 → 품목군 「Iron or steel products」로 조회됨." CN 툴팁 "CN 코드 EU가 쓰는 8자리 품목 분류 코드. 관세 HS코드와 앞 6자리가 같고 뒤 2자리가 더 붙습니다." — 관세사 없이도 이해됨.
- "품목 용도" 선택지: "CBAM 신고 대상 / 비CBAM 공동산출물 / 폐기물·재활용 / 내부소비". 탄소강 나사는 EU에 안 나가니 "비CBAM 공동산출물"로 골랐다. 다만 이 제품도 CN상으로는 CBAM 품목이라 "비CBAM"이라는 말이 딱 맞지는 않는다(‘EU 미수출’이라는 선택지가 있으면 더 명확). 어떤 뜻인지 설명 문구가 없어서 내 해석으로 골랐다.

## 6. 3단계 생산공정 — 구조 결정(2공정) 및 STS 공정 저장 PASS
- 지도로 돌아오니 2단계 상자가 "✓ 2 제품·CN 코드 / 제품 1개 · CN 확인"(비CBAM으로 넣은 탄소강은 안 셈), 3단계 "← 지금 여기 · 공정과 생산량을 연결", "2 / 6 완료", 부제 "STS 십자홈붙이 나사 … · CN 73181552 · 2025년 연간".
- 제품 화면 하단에 "산정 초안 만들기 — 제품군에 맞는 생산공정과 매입 소재 입력 틀을 자동 생성합니다 [생성]"이 있었지만, 우리 공장은 공용 라인 + 탄소강 전용 열처리로라는 구조를 내가 직접 정하고 싶어서 누르지 않았다(자동 생성이 제품별로 공정을 만들어 버리면 다시 정리해야 할 것 같아서). 대신 3단계 「상세 입력」(/processes)으로.
- /processes 상단 문구: "D_Processes / 생산량·전력·직접배출 입력 — 제품을 만들 때의 생산량, 전력 사용량, 연료·공정 직접배출을 입력하는 곳입니다." 카드 "등록 공정 0 / 제품 생산라인 0 / 전력 사용량 0 MWh / 배출원 검토 0".
- 안내 박스 「같은 제품의 여러 생산경로 처리」: "같은 제품이면 우선 통합 — 기본 검토 … 모든 경로를 포함하는 단일 공정으로 보는 방식이 기본 검토 출발점입니다." / "분리하려면 사유 기록 — 근거 필요: 별도 제품군, 별도 설비, 별도 고객계약, 품질 차이 등 공정을 나눌 합리적 사유와 자료 보관이 필요합니다." / "배분 기준 명확화 — 확정기간에는 몰 비율 또는 질량 비율 등 배분 기준을 명확히 남겨야 하므로 제품 생산라인 배분 합계를 먼저 확인하세요."
- 「산정경계 포함·제외 검토」: "철강의 절단, 도금, 용접, 마감 등 후단 공정은 제외 후보가 될 수 있으나 최신 기준과 거래 품목을 기준으로 확인해야 합니다." → 우리 탄소강 도금은 외주라 어차피 우리 배출이 아니다. 산세·부동태는 CO₂가 안 나오지만 전기를 쓰니 "포함 공정"으로 두기로.
- **공정 1개 vs 2개 결정(§8-2·3 연결)**: 한 공정에 STS·탄소강 두 라인을 넣고 질량 배분하면 탄소강 전용 열처리로 가스(486,000 Nm³)가 STS에도 톤수 비율로 얹힌다 — 이건 사실과 다르다. 앱이 "분리하려면 사유 기록: 별도 제품군, 별도 설비"라고 했고, 우리는 (1) 제품군이 다르고(STS vs 탄소강) (2) 열처리로는 탄소강 전용 설비라는 분명한 사유가 있다. 그래서 **공정 2개**: ① STS 나사 공정(공용 압조·전조 + STS 전용 산세), ② 탄소강 나사 공정(공용 압조·전조 + 탄소강 전용 열처리). 공용 전력(계량기 1개)과 공용 보일러 가스는 뒤 단계에서 두 공정에 나눠야 하는데, 폼 안내에 "연결된 배출원 합계(공용 계량기 정합계수 보정 후)를 저장할 때 자동으로 씁니다"라고 돼 있어 배출원(4단계) 화면에 공용 계량기 기능이 있는 듯하다. 배분 비율은 기술팀 60% 추정(근거 문서 없음)보다 앱이 원칙이라고 쓴 "질량 기준"(3,240:1,860)을 쓸 생각이다 — 4·5단계에서 확인.
- 신규 공정 폼 구조: "1. 공정 기본정보 필수"(공정명 / 생산경로(Route) / 보고기간 / 연결 제품 / 총 생산량(t)), "2. 제품 생산라인 배분 검토용"("… 불량·부산물·스크랩은 「활동수준 제외」로 표시하면 분모에서 빠지고 배출 0으로 기록됩니다." 라인별: 라인명 / 제품 / 생산량(t) / 배분기준 "질량 기준 (규정 원칙 — 기능단위)" 또는 "사용자 지정 배분 (규정 예외 — 사유 필요)" / 사용자 지정 배분율(%) / 활동수준(점 F) "미지정 (포함으로 산정 · 확인 필요)" / "활동수준 포함 (판매 가능 · 전구물질로 사용)" / "활동수준 제외 (불량 · 부산물 · 폐기물 · 스크랩 → 배출 0)"), "3. 생산량과 배출량 필수"(시장 출하량 / 내부 소비량 / 직접귀속배출량 + 산정방식 "미지정(수기 값 사용)" / "배출원 자료 합계 (권장 — 배출원 자료로 근거가 남음)" / "사용자 입력(수기 값) — 사유 필요" / "활동자료 템플릿 업로드 값" / 전력 사용량(MWh) / 전력 배출계수 기본 0.47 / 전력 EF 출처 유형).
- 「이 값 어디서?」 도움말이 실제로 유용했다: 직접귀속배출량 "연료 사용량 × 배출계수(고지서·계측기 검침) / 단위 주의: 활동량(t/Nm³)과 NCV(GJ/단위) 기준이 같아야 함 / … / 배출원 자료를 입력하면 합계를 이 값에 적용할 수 있음", 전력 사용량 "한전 전기요금 고지서 연간 합계 (kWh ÷ 1000 = MWh)", 전력 배출계수 "원칙: EU Commission 제공 국가/지역 계통 기본값(IEA 기반) / 실측 EF는 발전소 직접 연결 또는 PPA에 한해 허용 / ⛔ Guarantees of Origin·녹색인증서로 EF를 낮출 수 없음", "EU 예제값 채우기 (0.833)". → §8-5 답: 내가 아는 0.4747(환경부)이 아니라 EU가 주는 한국 계통값을 써야 하는 것 같다. 그 값이 얼마인지는 여기서 안 보인다(기본 0.47이 그건지 불명). 5단계에서 확인.
