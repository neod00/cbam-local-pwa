## 1. 믹스 계산 (검증 케이스)
같은 원료(선재 CN 7213)를 2개 공급사에서 조달:
| 공급사 | 소비량 | 직접 SEE | 간접 SEE |
|---|---|---|---|
| X | 600 t | 2.0 | 0.1 |
| Y | 400 t | 3.0 | 0.2 |
| **가중(믹스)** | **1,000 t** | **2.4** | **0.14** |

- 가중 직접 = (600×2.0+400×3.0)/1000 = **2.4**
- 가중 간접 = (600×0.1+400×0.2)/1000 = **0.14**

## 2. 등가성 — 제품 SEE (공정: 강선 1,000t, 자체 직접 200)

| 방식 | 보고용 SEE(직접) | 간접 | 총 |
|---|---|---|---|
| 가중 단일 행 (믹스 헬퍼) | **2.6** | 0.14 | 2.74 |
| 다중 행 (공급사별, 트리거 테스트) | 2.6 | 0.14 | 2.74 |

- 자체 직접 0.2 + 전구물질 직접 2.4 = **cbam_basis 2.6** (Annex II direct-only)
- 자체 간접 0 + 전구물질 간접 0.14 = **0.14**
- 총 2.74 = 2.6 + 0.14 ✅
- **가중 단일 행과 다중 행이 완전히 동일** → 믹스 헬퍼는 SEE 값 관점에서 정확·회귀 없음.

- 최종재 SEE 계산에는 소비량 가중이 공급사별 합산과 수학적으로 동일 → 값 정확.
