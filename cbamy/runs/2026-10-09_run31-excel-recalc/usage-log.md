# run31 — EU 복사본 실제 엑셀 재계산 (run30 후속)

대상: main(#117 머지 후). 자료: run30의 EU 공식 예제 「Steel 3 Screws and nuts」 입력 상태.

## 절차
1. run30에 남아 있던 프로젝트(이중계상 + 전력계수 자리값 상태)를 `/submit`에서 열면 판정이 **막힘**(#117) — 이 상태에서는 파일을 만들 수 없음을 확인.
2. 지도 4단계(배출원 자료) 화면의 삭제 버튼으로 나누기 전 공장 전체 가스 행(1,837.5 t)을 지움 → 판정 「보낼 수 있습니다. 다만 3가지…」(주의), 파일 버튼 활성.
3. `/submit`에서 EU 복사본 내려받기 → `scripts/excel-recalc-check.ps1`(실제 Excel 전체 재계산).
4. 고계수 공정의 전력 계수 자리값 0.47(출처 없음)을 0.833(원산지국 계통 평균)으로 고치고 다시 내려받기 → 재계산.

## 결과 (직접 / 간접 / 합계, tCO₂e/t)
| 단계 | 고합금(스테인리스) | 탄소강 | 오류 셀 |
|---|---|---|---|
| 2단계 후 (전력계수 0.47 남음) | 1.9524 / 2.2062 / 4.1586 | 2.0069 / 0.4066 / 2.4135 | 0 |
| 4단계 후 (0.833) | 1.9524 / **2.2788** / **4.2312** | 2.0069 / 0.4066 / 2.4135 | **0** |
| 공식 Summary_Products | 1.9524 / 2.2788 / 4.2312 | 2.0069 / 0.4066 / 2.4135 | — |

- 엑셀이 다시 계산한 값 = 앱 엔진 값(`analyze-state.mjs`) = 공식 예제 값. 두 제품 모두 일치.
- 2단계 후 간접 2.2062는 앱이 이미 「같은 계량기인데 공정마다 전력 계수가 다릅니다(0.833 / 0.47)」라고 알리던 상태 그대로의 값이며, 엑셀 복사본과 앱 값이 서로 같다(파일이 앱과 다르게 나가는 문제 없음).
- 오류 셀(#N/A·#REF! 등) 0건 — 두 번 모두.

## 부수 관찰
- 숨겨진 브라우저 창에서는 `/submit`이 값을 읽는 데 30~40초 걸림(템플릿 엑셀 검증). 창을 앞으로 가져오면 정상. 앱 결함 아님(run30 기록과 동일).
- 할 일 화면의 「고치러 가기」(V01)는 지도 `/`로만 연결됨 — 공정 수정 화면(`/processes?edit=…`)으로 바로 가면 더 낫다(P2, 미반영).
