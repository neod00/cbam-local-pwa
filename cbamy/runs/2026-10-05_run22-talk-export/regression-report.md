# run22 — 질문으로 입력(/talk)으로 만든 프로젝트의 EU 사본·백업·모바일 (2026-10-05)

대상: main a530a92 (PR #105 머지 직후), 운영 빌드, Playwright + 실제 Excel 16 (`scripts/excel-recalc-check.ps1`).
run20에서 생략했던 E~F 시나리오를 채운다.

| 시나리오 | 결과 |
| --- | --- |
| 빈 프로젝트 → /talk 전 질문(대일기업 STS 나사 단일 제품) | 기준 SEE **1.212**, 지도 화면도 1.212 |
| 그 프로젝트의 EU 사본을 Excel에서 전체 재계산 | `Summary_Products` 직접 1.2119 / 간접 0.5077 / 합계 1.7196 = 앱(1.212 / 0.508 / 1.720). **오류 셀 0건** |
| 백업 내보내기(5.4 KB) → 저장소 비우기 → 복원 → /talk | 칩 8개·기준 SEE 1.212 그대로 |
| 모바일 폭 375px의 /talk | 가로 넘침 0px |
| 비대상 CN(8311 피복봉) | 경고 문구는 뜨지만 저장은 막지 않고 다음 질문(생산량)으로 간다. 막대는 「간접배출 관련성을 판정하지 못해 기준 범위가 정해지지 않았습니다 — 확인 필요」라고 말한다 |

## 판단
- 결함 없음. 코드 변경 없음(보고서만).
- 8311 동작은 S1 설계(「CN 안내는 막지 않는다」, 지도 화면과 같음)에 따른 것이다. 다만 담당자가 「비대상」 경고를 보고도 끝까지 입력할 수 있다 — 실사용 시험에서 혼동이 나오면 그때 「이 제품은 CBAM 대상이 아닐 수 있습니다, 계속할까요?」 확인을 검토한다.

## 아직 안 한 것
- 보고기간이 둘이고 지도에서 EU 문서용으로 다른 기간을 고른 경우의 /talk 표시.
- 실제 사용자(외부 담당자) 시험.
