## 손계산 대조 (B)
- 직접 연료: 128,400 Nm³ × 0.037 GJ × 56.1 /1000 = 266.51988 tCO₂e (저장값 일치)
- 전구물질 EU 기본값 3.485664 × 1,050 t = 3,659.95
- 기준 SEE = (266.52 + 3,659.95) / 3,240 = **1.212** (화면 1.212)

## 발견한 결함
1. **(문구, 수정함)** 안내 문구가 이미 들어간 기능을 "아직 준비 중"이라 말함. 머리말 "결과 확인은 아직 지도 화면에서…"와 완료 카드 "다음 질문(같이 쓴 에너지 나누기·결과 확인)은 아직 준비 중" — S5에서 요약·나누기를 넣고 문구를 안 고침. 사용자가 결과를 보고도 "아직 안 됐다"고 오해할 수 있음. → 문구 수정, S2 게이트가 옛 문구 재등장을 막음.

## 관찰(결함 아님)
- 시험 중 제 조회 코드가 틀린 저장소 이름으로 멈춘 일이 있었으나 앱과 무관.
- 경고 3건(배출계수 출처 유형 미분류, 법정 필수 항목, UN/LOCODE)은 규정 항목이라 정상. 요약이 "막는 항목 없음 + 확인 3건"으로 제대로 구분함.
- 다중 기간에서 사용자가 지도에서 다른 기간을 EU 문서용으로 골랐을 때의 /talk 표시는 이번에 시험하지 않음(고른 기간 설정은 결과 계산에는 반영됨).
