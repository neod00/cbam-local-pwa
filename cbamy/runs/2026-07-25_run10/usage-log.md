## 2. PR #46 — 계수 출처 유형

### 2-1. 화면에 드러났는가 → PASS

4단계 「배출원 추가」 폼에 「계수 출처 유형」 칸이 있다. 선택지 4개(분류 전 / EU·IPCC 기본계수 /
국가 인벤토리·공공 통계 / 공급사 보증값·시험분석)이고 도움말은:

> 이 계수가 어디서 온 값인지. 모르면 「분류 전」으로 두세요 — 앱이 대신 정하지 않습니다.

### 2-2. 「분류 전」이 실제로 저장되는가 → PASS

배출원을 하나 만들어(`회귀-미분류-테스트`, 유류·기타 100 t) 「분류 전」으로 저장했다.
IndexedDB 확인: `factor_source_type: "UNCLASSIFIED"`. 자리값으로 대체되지 않는다.

### 2-3. 준비도 경고가 되살아났는가 → PASS

저장 직후 지도 8단계가 「생성할 수 있습니다」 → **「확인 항목 1건 검토」**로 바뀌었다.
7단계 패널에 정확한 문구가 떴다:

> 회귀-미분류-테스트: 배출계수 출처 유형이 분류되지 않았습니다.
> EU/IPCC 기본계수, 국가 인벤토리, 공급사 보증값·시험분석 중 하나로 근거를 정리하세요.

원래 결함(자리값이 채워져 이 경고가 조용히 꺼짐)이 해소됐다. 삭제 후 경고도 함께 사라졌다.

### 2-4. 그러나 — 유형을 바꾸면 내 선택이 지워진다 → **FAIL (신규 P2-run10-01)**

실제 클릭으로 재현:

1. 계수 출처 유형 = **「국가 인벤토리·공공 통계」** 선택
2. 배출원 유형만 「도시가스」 → 「유류·기타」로 변경
3. 계수 출처 유형이 **「EU/IPCC 기본계수」로 조용히 바뀜**

바로 아래 도움말은 「앱이 대신 정하지 않습니다」라고 적혀 있다. 상세는 개선 제안서.

### 2-5. 수정 경로 — 처음에 잘못 봤다

「수정에서도 덮어쓴다」고 관찰했으나 **틀렸다.** 수정 중에는 유형 드롭다운이 `disabled`이고
(`panels.tsx:1160`) 「유형은 바꿀 수 없습니다. 종류가 통째로 달라졌다면 지우고 다시 등록하세요」라는
안내까지 있다. 내가 합성 이벤트로 `disabled`를 우회했던 것이고, 실제 사용자에게는 일어나지 않는다.
**철회한다.** 저장된 값을 다시 열면 그대로 표시되는 것도 확인했다(NATIONAL_INVENTORY 유지).
