## 2. 시간순 조작 기록

1. **새 프로젝트** — 확인창 2개(삭제 경고 → 백업 제안). 백업 수락 → `cbam-backup-2026-07-24.cbam` 저장됨. 지도가 0/6으로 초기화.
2. **1단계** — 사업장 `Dongseong Special Steel` + 기간 `2025 Annual` 저장.
   - 관찰: 기간 저장 직후 패널이 **자동으로 2단계로 이동**. 방금 만든 수정 버튼을 볼 기회가 없음 (§3 N-08-05).
   - 1단계로 되돌아가 「사업장 수정」·「기간 추가」·행별 수정/삭제 확인.
3. **다중 기간 시험** — `2026년 연간` 추가 → 「8단계 EU 문서에는 맨 위 기간만 기재됩니다」 경고 정상 노출. 다만 **목록 순서가 생성순도 날짜순도 아님**(§3 N-08-01). 확인 후 삭제.
4. **2단계** — 슬래브 72189911 / 열연 평판재 72191310 / 봉강 72210010 등록.
   - CN 판정이 전부 「EU 공식 Communication Template(판본 20241213)의 CN 목록에서 조회됨」으로 표기. 접두 규칙 진술 없음 — 종전 지적 해소 확인.
5. **3단계** — P1 전기로 제강+연주 2,234,000 t(슬래브) / P2 압연·정정 1,133,000 t(시트·봉강 잠정 균등배분) 등록.
6. **4단계** — LNG 164,000 t 입력 → 574,656 tCO₂e. 이후 158,400으로 수정 → 555,033.6 재계산 확인.
7. **5단계** — P2 324,700 MWh · P1 1,563,800 MWh (EF 0.4594, 「국가/지역 계통 평균 기본값」). 공정 전환 회귀 확인(R1·R2).

## 4. 산정 한계 — 이 결과는 제출용이 아니다

이 run의 SEE(0.426 tCO₂e/t)는 **앱 동작 검증용 수치이지 시나리오의 정답이 아니다.** 이유:

- 전기로 직접배출의 대부분(고철·흑연전극·매입 강괴 **물질수지**, 부원료 **공정배출**)을 지도 패널로 입력할 수 없다 → LNG 연소분만 반영됨 (§3 N-08-02).
- LNG 배출계수도 클라이언트 실측(56.1 tCO₂/TJ)이 아니라 앱 프리셋(73)이 적용됨.
- P2 제품별 생산량(시트/봉강)은 클라이언트가 「환경팀 확인 중」이라 잠정 균등배분함.
- 전력 EF 0.4594는 클라이언트 진술값이며 CBAM 인정 근거 미확인 — 확인 필요.
- 전구물질 전력계수(인도네시아 0.717 등)는 잠정치 — 확인 필요.
- P1 조강이 P1 산출물이면서 P2 투입물이라, 지도의 「전체 합계」 SEE는 두 공정을 단순 가중평균한 값이다. 품목별 SEE는 `/results`에서 따로 확인해야 한다.
