## 시험 중 발견해 고친 것
1. 제목 자르기가 「Co., Ltd. 」의 마침표에서 잘려 카드 제목이 회사 이름뿐이었다 → 한글·닫는 괄호 뒤의 마침표에서만 자른다(게이트가 영문 약어·소수점 사례를 잠금).
2. 같은 잠정 실측 경고가 준비도 검사와 영향 상자 카드로 **두 장** 나왔다 → 한 장으로 합침.
3. 공급사 카드 제목에 사용자가 이름 칸에 적어 둔 메모(「3회 요청 미회신」)가 섞여 어색했다 → 제목은 「실측값 받기 — 원료 N개」, 공급사 이름은 카드 위 이름표.
4. 빈 프로젝트에 「보고기간이 없습니다 — 먼저 해결」 오류가 떴다 → 공정이 생기기 전에는 점검 오류를 보이지 않는다.

## 아직 없는 것 (목업 대비)
- 항목을 **이 화면에서 바로 고치는** 입력칸(목업의 법인 등록번호 입력·위치 코드 목록): 지금은 고칠 화면으로 가는 링크다. 밖에서 산 열 「안 씁니다」만 이 자리에서 답한다.
- 「요청서 보기」 같은 공급사 카드의 직접 연결(요청서는 지도 6단계 안에 있어 단계 이동 링크만 있다 — 지도 화면은 주소로 단계를 못 고른다).
- 목업의 「제출」·「보관함」 전용 화면.
- 「공급사에게 받을 것」의 「요청서에 담김」 상태: 앱이 요청서를 만든 사실을 저장하지 않아 보이지 않는다.
