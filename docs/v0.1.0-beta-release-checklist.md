# v0.1.0-beta Release Checklist

이 문서는 CBAM Local PWA `v0.1.0-beta`를 제한 배포하기 전 Go/No-Go 판단에 사용하는 체크리스트다.

## Release Position

- 배포 명칭: `CBAM Local v0.1.0-beta`
- 배포 성격: 제한 베타 또는 Pilot 배포
- 대상: 내부 검토자, 제한된 기업 실무자, CBAM 컨설턴트 검토자
- 제외: 정식 공개 배포, 공식 검증 대체, 법률/세무/검증 자문, 다중 사용자 SaaS
- 저장소: Private GitHub 저장소 유지
- 배포 방식: PWA URL 배포, 소스 저장소 공개 없음
- 데이터 원칙: 기업 입력자료, EU 템플릿, `.cbam` 백업은 기본적으로 브라우저 로컬에서 처리

## Go Criteria

아래 항목이 모두 충족되면 `v0.1.0-beta` 제한 배포를 진행할 수 있다.

- `npm.cmd run verify`가 통과한다.
- `npm.cmd run release:status` 결과에서 남은 blocker가 운영자가 수용 가능한 수준이다.
- 공식 EU Communication template 기반 `verify:local-eu-template`가 통과한다.
- 생성된 Export 복사본을 Microsoft Excel에서 열어 `Summary_Products` 공식 수식 재계산을 확인했다.
- 가상 데이터로 브라우저 전체 리허설을 완료했다.
- `.cbam` 백업 내보내기와 가져오기 흐름을 확인했다.
- 배포 산출물에 `CBAM_documents/`, 공식 EU 템플릿, 실제 회사자료, `.cbam`, `.env*`가 포함되지 않았다.
- 무료 사용 고지, 면책, 로컬 데이터 원칙, 최신 EU 템플릿 직접 업로드 안내가 사용자에게 보인다.
- 문의 채널은 `openbrain.main@gmail.com`으로 안내한다.
- 배포 후 첫 화면에서 실제 회사자료 입력 전 베타/검토용 성격을 이해할 수 있다.

## No-Go Criteria

아래 항목 중 하나라도 발견되면 배포를 보류한다.

- Export 복사본에서 공식 EU 템플릿 수식 셀이 값으로 덮어써진다.
- Excel 재계산 결과와 앱 검토값의 차이를 설명할 수 없다.
- 브라우저 저장 데이터가 의도하지 않은 서버 API로 전송된다.
- 배포 저장소 또는 배포 산출물에 실제 회사자료, 공식 EU 템플릿 원본, reference workbook, `.cbam` 백업이 포함된다.
- 사용자가 “이 앱만으로 EU 제출이 완료된다”고 오해할 수 있는 문구가 남아 있다.
- 약관/고지 문구에 운영자 정보, 책임 제한, 문의 채널이 빠져 있다.
- 모바일 또는 데스크톱 주요 화면에서 Export 전 필수 흐름을 진행하기 어렵다.

## Browser Rehearsal Scope

가상 데이터는 `docs/mvp-fictional-dataset.md`를 사용한다.

- 새 브라우저 프로필 또는 시크릿 창에서 시작한다.
- 사업장 정보를 입력한다.
- 보고기간을 확인한다.
- 품목을 등록하고 CN 코드 검토를 확인한다.
- 생산공정과 제품 생산량을 입력한다.
- 배출원 자료를 입력한다.
- 구매 전구물질을 입력한다.
- 산정 결과에서 `CBAM 기준 SEE`와 `참고용 총 SEE`를 구분해 확인한다.
- SEFA/CBAM 인증서 시나리오 안내가 표시되는지 확인한다.
- EU Export에서 최신 EU 원본 템플릿을 업로드한다.
- Export 복사본을 생성한다.
- Excel에서 공식 수식 재계산 결과를 기록한다.
- `.cbam` 백업을 내보내고 다시 가져온다.

## Deployment Smoke Test

배포 URL에서 아래를 확인한다.

- Dashboard가 열린다.
- 주요 메뉴가 열린다: 사업장, 보고기간, 품목, 생산공정, 배출원 자료, 구매 전구물질, 산정 결과, 시나리오, EU Export, 설정.
- PWA 설치 안내 또는 브라우저 설치 메뉴가 동작한다.
- Network 탭에서 회사 입력값 저장 시 별도 서버 API 요청이 발생하지 않는다.
- EU 템플릿 업로드와 `.cbam` 백업이 서버 업로드 없이 브라우저에서 처리된다.
- 업데이트 안내가 `/release-notes`로 연결된다.

## Release Notes

`v0.1.0-beta` 공지에는 반드시 포함한다.

- 무료 베타/Pilot 버전이다.
- 공식 검증, 법률 자문, EU 제출 책임을 대체하지 않는다.
- 사용자는 최신 EU 원본 템플릿을 직접 다운로드해 업로드해야 한다.
- Export 후 Microsoft Excel에서 공식 수식 재계산 결과를 확인해야 한다.
- 브라우저 로컬 저장소 삭제 시 데이터가 사라질 수 있으므로 `.cbam` 백업이 필요하다.
- PWA 특성상 브라우저에 전달되는 JavaScript 번들은 사용자가 확인할 수 있다.
- 문의: `openbrain.main@gmail.com`
