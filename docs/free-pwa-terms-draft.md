# Free PWA Terms Draft

Status: LEGAL_REVIEW_REQUIRED

이 문서는 CBAM Local PWA 무료 베타 배포에 사용할 수 있는 약관/고지 초안이다. 운영 문구 정리는 완료했지만, 최종 약관으로 공개하기 전에는 법무 또는 운영 책임자의 검토가 필요하다.

Public draft URL: `https://cbam-local-pwa.vercel.app/terms`

## 1. 무료 사용 범위

- 사용자는 배포된 CBAM Local PWA를 통해 자사 CBAM 산정 자료를 브라우저 로컬 환경에서 입력, 검토, 백업, Export할 수 있다.
- 무료 버전은 CBAM 업무 정리와 제출 준비를 돕는 업무 보조 도구다.
- 앱은 EU 원본 템플릿이나 공식 기준자료 파일을 내장하지 않는다. 사용자가 보유한 최신 공식 파일을 직접 업로드해야 한다.
- 무료 사용은 소스코드 공개, 재배포 허가, 상업적 호스팅 대행 허가, 계산 로직에 대한 권리 이전을 의미하지 않는다.
- 무료 버전의 기능, 화면, 배포 방식은 사전 공지 후 변경, 중단, 분리될 수 있다.

## 2. 금지 또는 제한 사항

- 별도 서면 허가 없이 소스코드, 빌드 산출물, 화면, 계산 로직을 복제, 재배포, 판매, 임대, 호스팅 대행할 수 없다.
- 앱을 변형해 제3자에게 유료 서비스로 제공할 수 없다.
- 실제 기업자료, `.cbam` 백업 파일, EU Communication Template 원본 또는 작성 복사본을 공개 채널, 이슈, 이메일, 메신저에 공유하지 않아야 한다.
- 자동화된 대량 사용, 보안 우회, 악의적 분석, 서비스 방해 행위는 제한될 수 있다.

## 3. 데이터 처리 원칙

- 무료 PWA는 사용자의 CBAM 입력자료를 브라우저 로컬 저장소에 저장하는 것을 기본 원칙으로 한다.
- 사용자가 선택한 EU 템플릿과 기준자료 파일은 브라우저 안에서 처리되며, MVP 기준으로 서버 업로드를 전제로 하지 않는다.
- 무료 라이선스 등록 또는 업데이트 확인 기능이 연결되는 경우에도 이메일, 회사명, 담당자명, 국가, 업종, 앱 버전, 라이선스 상태, 공지 확인 상태 같은 배포 관리 정보만 처리한다.
- 라이선스 또는 업데이트 확인은 생산량, 배출량, 전구물질, 공급업체 자료, 산정 결과, EU 템플릿, `.cbam` 백업 파일을 수집하기 위한 기능이 아니다.
- 브라우저 데이터 삭제, 프로필 초기화, 기기 교체, 보안 프로그램 정리로 로컬 데이터가 사라질 수 있다.
- 사용자는 중요한 입력 후 `.cbam` 백업 파일을 회사 보안정책에 맞게 별도 보관해야 한다.
- 사용자는 회사 내부 보안정책과 개인정보 처리 기준에 따라 입력자료, 백업 파일, 제출용 Excel 파일을 관리해야 한다.

## 4. 공식 자료와 제3자 자료

- EU 원본 템플릿, EU 기준자료, 법령, 번역서, 컨설팅 자료의 권리는 각 제공자에게 있다.
- 앱은 사용자가 보유한 공식 또는 허가된 자료를 로컬에서 읽어 업무 편의를 제공할 뿐, 해당 자료의 배포권을 부여하지 않는다.
- 사용자는 공식 제출 전 최신 EU 규정, 최신 공식 템플릿, 적용 기간별 기준자료를 직접 확인해야 한다.

## 5. 업데이트와 공지

- 무료 PWA는 오류 수정, 공식 템플릿 대응, 보안 안내를 위해 선택, 권장, 필수 업데이트 안내를 표시할 수 있다.
- 업데이트 안내가 표시되더라도 기존 브라우저 로컬 데이터가 서버로 자동 업로드되지는 않는다.
- 사용자는 업데이트 전후 중요한 입력자료를 `.cbam` 백업으로 보관해야 한다.
- 더 이상 지원하지 않는 버전은 주요 기능 사용 전 업데이트 안내를 표시할 수 있다.

## 6. 지원 범위

- 무료 PWA는 별도 유료 계약이 없는 한 개별 컨설팅, 법률 자문, 제출 대행, 공식 검증 대응, 긴급 대응 SLA를 포함하지 않는다.
- 기능 문의, 오류 제보, 개선 요청은 `openbrain.main@gmail.com`으로 받을 수 있다.
- 문의 시 민감한 회사자료, EU 제출 파일, `.cbam` 백업 파일은 첨부하지 않는 것을 원칙으로 한다.

## 7. 책임 제한

- CBAM Local PWA는 산정과 제출 준비를 돕는 업무 보조 도구다.
- 앱은 법률 자문, 관세/세무 자문, 공식 검증, 회사 내부 승인, 최종 제출 책임을 대체하지 않는다.
- 사용자는 제출 전 내부 검토, 필요한 경우 전문기관 검증, 최신 EU 규정과 공식 양식 확인을 수행해야 한다.
- 산정 결과, Export 파일, 제출자료의 정확성과 제출 책임은 사용자에게 있다.
- 무료 PWA는 명시적 또는 묵시적 보증 없이 현재 상태로 제공된다.
- 운영자는 법령이 허용하는 범위에서 브라우저, 기기, 네트워크, 보안 프로그램, 공식 템플릿 변경, 사용자 입력 오류로 인한 데이터 손실 또는 제출 오류에 대한 책임을 제한한다.

## 8. 사용 제한과 중단

- 약관 위반, 무단 재배포, 상업적 전용, 보안 위협, 악의적 자동화 사용이 확인되는 경우 무료 라이선스 또는 접근이 제한될 수 있다.
- 접근이 제한되더라도 사용자의 기존 브라우저 로컬 데이터나 `.cbam` 백업 파일이 서버로 이전되거나 수집되지는 않는다.
- 사용자는 접근 제한 또는 서비스 중단 전에 가능한 범위에서 `.cbam` 백업을 내려받아 보관해야 한다.

## 9. 소스 보호와 고급 기능

- 저장소는 원본 소스코드 비공개를 원칙으로 한다.
- PWA 특성상 브라우저로 전달되는 JavaScript 번들은 사용자가 확인할 수 있다.
- 보호가 필요한 고급 계산 로직, 고객사/프로젝트 관리, 공동작업, 관리자 콘솔, Docker/on-premise 배포는 향후 별도 버전에서 제공될 수 있다.

- 최종 서비스명
- 운영자명 또는 회사명
- 문의 채널: `openbrain.main@gmail.com`
- 개인정보 처리 안내가 별도 문서로 필요한지 여부
- 무료 라이선스 등록 시 수집하는 최소 개인정보 항목
- 책임 제한 문구의 적용 법령과 관할
- 재배포 금지 위반 시 조치 기준
- 사용자 고지 화면 또는 릴리즈 공지에 표시할 약관 링크
