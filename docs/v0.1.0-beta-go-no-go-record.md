## Decision Notes

- 운영자 정보(운영자명·사업자등록번호 없음·주소 비공개·개인정보 보호책임자·전속 관할 법원·시행일 2026-11-01)는 운영자가 직접 확정했다.
- 전력 배출계수 두 값(2025/2621 부속서 II의 한국 0,475·기타 0,465)을 앱에 내장한다. 그 표는 IEA 자료이고 규정 본문이 CC BY-NC-SA 4.0(비상업 목적에 한해 재사용)을 고지한다. 앱은 무료로 배포하지만 앱 밖 컨설팅 수익으로 이어지는 구조라 「비상업」에 해당하는지는 불확실하다 — **운영자가 이 위험을 알고 내장한 채 공개하기로 결정했다(2026-10-17)**. 공개 전에 IEA에 서면 문의해 허락을 받는 것이 권장되며, 문제가 제기되면 두 값과 적용 단추를 빼고 사용자 직접 입력으로 되돌린다(몇 줄 수정).
- 약관 전체와 공지문은 운영자 본인이 승인했다(2026-10-17). **외부 법무 검토는 받지 않았다** — 책임 제한 조항, 개인정보 국외 이전·위탁 고지, 전력 배출계수 두 값의 IEA 라이선스(CC BY-NC-SA 4.0, 비상업 목적) 적합성은 법적으로 검토되지 않은 상태에서 공개한다.
- 약관·방침 시행일이 2026-11-01이다. 결정일은 실제로 결정한 날(2026-10-17)로 두고, 공개 예정일을 2026-11-01(시행일 당일 또는 이후)로 따로 적었다. 결정일을 미래 날짜로 적지 않는다.
- 개인정보 보호책임자는 「OpenBrain Inc. 대표」(직위)로 정했다(2026-10-17).

## How To Mark Release Ready

승인 후에는 아래 변경을 별도 커밋으로 남긴다.

1. `docs/free-pwa-terms-draft.md`의 `Status: LEGAL_REVIEW_REQUIRED`를 승인 상태로 변경한다.
2. `docs/free-pwa-release-announcement-draft.md`의 `Status: OPERATOR_REVIEW_REQUIRED`를 승인 상태로 변경한다.
3. `docs/mvp-rehearsal-report.md`의 `Release Blockers` 섹션에서 법무 검토 blocker를 제거한다.
4. 이 문서의 `Status: DECISION_REQUIRED`와 `Decision` 항목을 실제 결정으로 채운다.
5. `npm.cmd run release:status`가 `READY`인지 확인한다.
6. `npm.cmd run release:approval`이 통과하는지 확인한다.

권장 승인 상태 값:

- `Status: LEGAL_REVIEW_APPROVED`
- `Status: OPERATOR_REVIEW_APPROVED`
- `Status: GO`
