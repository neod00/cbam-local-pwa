# 시험 후 질문 (8개, 5분)

숫자나 회사 자료는 쓰지 않고, 느낀 점만 적어 주세요. 답은 메일(openbrain.main@gmail.com)이나 화면의 「막히셨나요? 알려 주세요」로 보내 주시면 됩니다.

1. 끝까지(결과 화면까지) 가셨나요? 못 갔다면 **몇 번 질문에서** 멈췄나요?
2. **이해하기 어려웠던 질문**이 있었나요? (질문 번호와 어떤 말이 어려웠는지)
3. **무슨 값을 넣어야 할지 몰랐던 칸**은요? (예: CN 코드, 순발열량, 배출계수, 소비량과 구매량의 차이)
4. 「모르겠어요 / 나중에 입력」을 몇 번 눌렀나요? 어떤 질문이었나요?
5. 결과 화면의 **숫자와 안내가 무슨 뜻인지** 말로 설명해 보세요. (예: 「중간 값」, 「기준 SEE와 총 SEE가 다르다」)
6. 이 결과를 **회사 안이나 수입자에게 설명할 때 쓸 수 있겠다**고 느끼셨나요? 아니라면 무엇이 모자란가요?
7. 기존에 쓰던 방법(엑셀·컨설팅 등)과 비교하면 어땠나요? (더 쉬움 / 비슷 / 더 어려움, 이유)
8. 다음에 또 쓰시겠습니까? 쓰려면 **무엇이 더 있어야** 하나요?
