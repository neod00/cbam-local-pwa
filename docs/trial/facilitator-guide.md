# 시험 진행자 가이드 (운영자용)

목표: 외부 담당자 2~3명이 질문 모드를 **혼자 끝까지** 쓸 수 있는지 보고, 막히는 곳을 찾는다. 계산 정확성은 내부 시험(run19~22, 손계산·Excel 재계산)으로 확인했다.

## 1. 시험 전 점검 (운영자)
- [ ] https://cbam-local-pwa.vercel.app/talk 가 열리고, 화면 머리말에 「막히셨나요? 알려 주세요」가 보이며, 누르면 창 아래 「이메일로 직접 문의하기」 링크의 제목에 질문 이름(예: 질문 5 구매 강재)이 들어 있다. (앱 안 문의폼은 무료 사용 등록이 있어야 보낼 수 있다 — 시험자는 메일 링크를 쓴다.)
- [ ] 이 시험에서 쓸 **가상 자료**로 직접 한 번 돌려 본다(아래 3). 결과가 1.212 / 1.720이어야 한다.
- [ ] 시험자 브라우저: 크롬 또는 엣지, 시크릿 창이 아님(닫으면 저장이 사라진다).
- [ ] 문의 메일(openbrain.main@gmail.com)을 확인할 사람이 정해져 있다.
- [ ] 시험자에게 `tester-guide.md`를 보냈고, **실제 회사 숫자를 메일로 보내지 말라**는 문구를 확인시켰다.

## 2. 시험 방식 두 가지
| 방식 | 언제 | 방법 |
| --- | --- | --- |
| A. 같이 보기(권장 첫 시험) | 첫 1~2명 | 화면 공유. **말없이 지켜본다.** 막혀도 먼저 알려 주지 않고 10초 기다린다. 그래도 막히면 어떤 말로 풀었는지 기록하고 알려 준다 |
| B. 혼자 해 보기 | 이후 | 안내문과 피드백 질문지만 보낸다. 막힌 곳은 「막히셨나요?」 메일로 받는다 |

## 3. 가상 자료(진행자 확인용 정답 있음 — 실제 업체 자료 아님)
| 질문 | 입력 |
| --- | --- |
| 1 | Daeil Fastener Co. / KR |
| 2 | 2025년 연간 |
| 3 | 파스너·볼트·너트 → 볼트·너트·스크류·와셔, 제품 「STS 십자홈붙이 나사」, CN 73181552 |
| 4 | 3,240 t |
| 5 | 네 → 선재(와이어로드), CN 72131000, 소비 1,050 t, 공급국 China, 「모르겠어요」+「EU 기본값 채우기」 |
| 6 | 도시가스 128,400 Nm³, 출처 「도시가스 고지서 2025」 |
| 7 | 3,500 MWh |
| 8 | 아니요 |

기대 결과: 기준 SEE **1.212**, 총 SEE **1.720**, 막는 항목 없음(확인 3건: 계수 출처 분류, 법정 필수 항목, UN/LOCODE). 막대는 「실측 비율 7%」.

## 4. 관찰표 (시험자 한 명당 한 장)
시작 시각 ____ 종료 ____ 방식 A / B

| 질문 | 멈칫한 시간(초) | 한 말·행동(그대로) | 도움 받음 | 「모르겠어요」 사용 |
| --- | --- | --- | --- | --- |
| 1 회사·공장 | | | | |
| 2 보고기간 | | | | |
| 3 제품·CN | | | | |
| 4 생산량 | | | | |
| 5 구매 강재 | | | | |
| 6 연료 | | | | |
| 7 전력 | | | | |
| 8 산 열 | | | | |
| 결과 화면 | | | | |

특히 볼 곳:
- **3번**: CN 8자리를 모르는 시험자가 어떻게 하는가(후보 코드 칩을 쓰는지, 포기하는지).
- **5번**: 「소비량」과 「구매량」을 헷갈리는가, 「EU 기본값 채우기」가 무슨 뜻인지 이해하는가.
- **6번**: 순발열량·배출계수 칸에서 멈추는가(임시 자리값을 그대로 두는가).
- **7번**: 0.47이 임시값이라는 안내를 읽는가.
- **결과**: 「중간 값」을 「최종 값」으로 읽는가. 「기준 SEE ≠ 총 SEE」를 이해하는가.
- 길을 잃었다고 하는 순간(어느 화면에서, 무엇을 찾았는가).

## 5. 성공 기준 (첫 시험 3명 기준)
- 3명 중 2명 이상이 도움 없이 결과 화면까지 간다(30분 이내).
- 결과 화면의 「중간 값/최종 값」 구분을 3명 중 2명 이상이 맞게 말한다.
- 같은 질문에서 **2명 이상** 멈추면 그 질문의 문구를 고친다(1명이면 기록만).

## 6. 멈추거나 되돌릴 조건
- 시험자가 실제 회사 숫자를 메일·채팅으로 보내면: 받지 말고 지우도록 안내(약관의 「민감자료 미첨부」).
- 계산 결과가 명백히 틀려 보이면(예: 가상 자료가 1.212가 아님): 시험을 멈추고 재현 후 수정한다.
- 저장이 사라졌다는 보고가 있으면: 브라우저 종류·시크릿 여부를 먼저 묻는다.

## 7. 끝난 뒤
1. 관찰표와 피드백을 모아 `cbamy/runs/<날짜>_trial1/`에 정리한다(실제 회사 숫자는 적지 않는다).
2. 멈춘 질문 순위와 고칠 문구 목록을 만든다.
3. 고친 뒤 같은 사람에게 다시 하지 말고 **새로운 1~2명**에게 한다.
