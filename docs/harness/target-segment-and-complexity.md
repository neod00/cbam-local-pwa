# CBAM_Platform 타겟 세그먼트 & 복잡도 정의

> 목적: 이 앱이 **누구를 위한, 어느 복잡도까지의** 도구인지 못 박는 전략 기준 문서.
> 근거: EU 공식 워크북 4종(고로·전기로·나사너트 + Communication Template) raw 재현검증 + 실제 한국 기업 5사 공개정보 조사 + 앱 코드(`calculation-engine.ts`, `cbam-product-rules.ts`, `cn-code-options.ts`, `local-db.ts`) 확인. 작성 2026-06.

## 0. 한 줄 정의
**CBAM 대상이지만 "쇳물을 만들지 않는(가공사)" 중소·중견 철강·금속 회사의 비전문 담당자가, 깊은 CBAM 지식 없이 직접 SEE를 산정하고 EU 템플릿까지 만드는 도구.**
- 포함: 강재(코일·선재·심선·후판)를 **사다가 가공**(신선·압연·제관·도금·피복)하는 회사.
- 제외: 쇳물을 만드는 **제철사**(고로·전기로 제강), **Mt급 다공장 대형사**의 전사 통합.

## 1. 복잡도는 3개 축으로 나뉜다
CBAM 산정 난이도는 "복잡하다/단순하다" 하나가 아니라 **독립된 3축**이다.

| 축 | 정의 | 부담의 본질 | 앱 책임 |
|---|---|---|---|
| **(A) breadth** 다제품 가공 | 강재 사다 가공, 공정 얕음. 제품·재질 가짓수 많음 | 품목 수·**대상/비대상 분류**·다제품 배분 | ✅ **IN — 핵심 가치** |
| **(B) depth** 다공정 제철 | 쇳물 만듦(용해→주조→압연 P1→P2), 물질수지가 산정 본체 | 사내 다단 전가·환원 공정배출 | ❌ **OUT** |
| **(C) scale** 대형 규모 | Mt급·다공장·다거점 | 전사 데이터 집계·거버넌스·감사 | 회사전체 OUT / **단일 공장 시범 IN** |

> **가장 중요한 갱신: "다제품 = 타겟 밖"이 아니다.** breadth는 IN이다. 타겟을 가르는 건 **depth(쇳물?) 또는 scale(Mt·다거점?)** 이지 제품 가짓수가 아니다.

## 2. 실제 기업 사례 (5사)

| 회사 | 제품 | CBAM CN | 생산구조 | 규모 | 복잡도 유형 | 타겟 |
|---|---|---|---|---|---|---|
| EU 예제 "나사·너트" | 패스너 2종 | 7318 | 가공 | 소(kt) | (A) 최소 breadth | **IN** |
| 현대종합금속 | 용접 와이어 수백 SKU | 7217 대상 **+ 8311 비대상 혼재** | 가공(강선재 매입) | 중견(kt) | **(A) breadth** | **IN** |
| 키스웰(KISWEL) | 용접재료 8패밀리 수백 SKU | 7217 대상 + 8311·비철 비대상 혼재 | 가공(선재·심선·강대 매입) | 중견(kt, ~3천억, 7거점) | **(A) breadth** (현대종합금속 쌍둥이) | **IN** |
| 현대비앤지스틸 | STS 냉연강판(단일 95%+) | **7219/7220** (indirect 포함) | 가공(STS 열연코일 매입→냉연·소둔) | 준대형(0.3Mt, ~7.4천억, 3공장) | **(C) scale弱** + breadth微 | **IN(경계)** |
| 세아제강 | 강관 전종 다규격 | 7304~7306 (거의 전량 대상) | 가공(HRC·후판 매입→제관) | **대형(1.6Mt, ~1.87조, 4공장+해외)** | **(C) scale強** + breadth中 | **OUT** (단일공장 시범 IN) |

**핵심 패턴**: 5사 전원 **depth(제철) 없음.** 진짜 용해·제강 다단 전가는 POSCO·현대제철·세아창원특수강(전기로 특수강) 몫. 한국 CBAM 대상 가공 SME/중견은 **(A) breadth 또는 (C) scale** 로 흩어진다.

## 3. 타겟 경계 (IN / OUT 컷오프)

**IN — 앱이 단독 책임지는 스윗스폿**
1. 생산구조 = **가공(converter)** — 쇳물 안 만듦(depth 없음).
2. 규모 = **중소·중견** — kt급(대략 ≤0.3~0.5Mt), 단일~소수 공장.
3. **breadth 환영** — 다제품·다재질·대상비대상 혼재는 책임 영역.

**OUT — 하나라도 해당 시**
1. 사내 **다공정 제철 전가체인**(용해→주조→압연 P1→P2) = depth.
2. **자체 직접배출이 산정 본체**(자사 용해·제련·환원 공정배출이 큼).
3. **Mt급 + 다공장 전사 통합**이 산정 본체(세아제강 전사).
4. **전구물질이 수십종·다국가**로 산정 본체.

> 경계선: 세아제강·비앤지스틸형도 **"단일 공장·소수 품목" 시범 스코프**로 좁히면 가공형 SEE 산정 자체는 IN.

## 4. CN 분류 주의 (비전문가 최대 함정)
같은 "용접봉"이라도 CN이 대상/비대상을 가른다:
- **맨 강철 와이어**(솔리드·SAW·TIG) = CN **7217/7223/7229** → **CBAM 대상**
- **피복·플럭스코어드·메탈코어드 용접봉** = CN **8311**(Ch83) → **CBAM 비대상**
- 비철(Ni/Al)·티타늄·플럭스 → 비대상
- STS 냉연 평판 = **7219/7220** → 대상(**indirect 포함**, 전력 EF 산정 관여)
- 강관 = **7304~7306** → 대상

## 5. 현재 앱 커버리지 (코드 확인)
- **(A) breadth: 구조적으로 잘 맞음.** 다제품 배분(`ProductOutputLine` MASS/MANUAL), 외부 전구물질 SEE 모델(`PurchasedPrecursor` direct/indirect, supplier_country, ACTUAL/SEMI/DEFAULT, markup), Annex II direct-only 자동제외 — 이미 구현. 엔진 정확성은 EU 예제 재현으로 입증.
- **(B) depth: 의도적 미커버(올바른 경계).** 엔진이 공정별 독립 계산이고 사내 P1→P2 자동전가 없음 → 제철 물질수지 못 함. 결함 아님.
- **(C) scale: 부분 커버.** 다공정·다기간 입력 가능하나 다거점 집계는 초기. export MVP 상한(공정10·전구20·배출원75·제품100). 세아제강 전사는 OUT.

## 6. 시급 보강 우선순위 ("비전문 담당자 직접 사용" 기준)
1. **CN 분류 가드레일** — 7217/7219/7220/7304~7306 기본 추가 + **8311(피복·코어드 비대상) 경고**. ⚠️ 현재 `cn-code-options.ts` 내장 13종에 이 코드들이 빠져 있음(EU 템플릿 가져오기로 보완은 되나 기본값 부실).
2. **다제품 복제·일괄입력** — "대표 1건 → 강종·치수 변형 복제" + 대상/비대상 일괄 태깅.
3. **전구물질 기본값 폴백 강화** — 미확인 시 EU 기본값 자동 + 출처/사유 자동 채움(SEE의 ~90%가 매입 강재).

## 7. 위저드(쉬운 입력) 방향 함의
- 위저드는 **첫 제품 익히기 + 단순 케이스 완결**용. breadth형은 "한 제품 위저드 → 나머지 복제"가 현실적.
- 위저드 핵심 스텝 = **전구물질(매입 강재) SEE 확보 핸드오프**(실측 입력 / EU 기본값 / 공급사 요청).
- 컷오프(depth·대형 전사) 감지 시 **풀워크플로/컨설팅으로 정직하게 안내**.
