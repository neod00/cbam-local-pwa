# 활동자료 서식 대조표 — 규정이 요구하는 것 vs 서식이 받는 것 (2026-10-10)

**질문**: 컨설턴트가 채운 엑셀 서식을 올리면 CBAM 요구사항이 충족되는가.
**답**: 계산에 필요한 자료는 거의 다 받는다. **보고서에 적어야 하는 것**은 절반쯤만 받는다 — 나머지는 앱 화면에서 따로 입력해야 하고, 일부는 앱에도 없다.

- 기준: Commission Implementing Regulation (EU) 2025/2547 **부속서 IV 1.1**(운영자 배출 보고서의 최소 항목 35개)과 **부속서 IV 2**(부문특정 파라미터). 원문: `CBAM_documents/EU Verification/OJ_L_202502547_EN_TXT.pdf` 78~85쪽.
- 대상: 이 앱의 지원 범위인 **강재를 사다 가공하는 철강 업체**(제품이 2023/956 부속서 II 품목 — 간접배출은 보고만 하고 인증서 기준에는 들지 않는다).
- 서식: `src/lib/activity-workbook.ts`(v2). 앱: 지도 1~8단계, `/report-inputs`(산정보고서 입력), 산정보고서(`calculation-report.ts`), EU 문서(`eu-template-export.ts`).
- 이 표는 코드와 원문을 읽어 만들었다. 「확인 필요」라고 적은 칸은 단정하지 못한 곳이다.

기호: **●** 서식으로 받는다 · **自** 서식 자료로 앱이 계산·자동으로 만든다 · **◐** 앱 화면에서만 받는다(서식에 칸 없음) · **○** 앱에도 없다 · **—** 이 대상에 해당 없음

## 4. 읽는 법

- **계산**(SEE)에 필요한 자료 — 생산량, 연료, 전력, 구매 강재 — 는 서식이 받고, 앱이 규정의 기본 방법으로 귀속한다. EU 공식 예제 하나와 가상 사례 하나에서 정답과 같았다(run33).
- **보고**에 필요한 자료는 사정이 다르다. 위 표에서 서식만으로 끝나는 줄(● · 自)은 35개 중 스무 개 남짓이고, 나머지는 ◐(앱 화면)·○(없음)·—(해당 없음)이다.
- 지금 `/submit`의 「보낼 수 있습니다」는 **EU Communication 엑셀을 만들 수 있다**는 뜻이지, 산정보고서의 「기재 필요」가 없다는 뜻이 아니다. `/report-inputs`의 빈 칸(부문특정 파라미터·전력 계수 근거·모니터링 계획·탄소가격)은 할 일·제출 화면의 점검에 들어 있지 않다 — 서식으로 올린 사람이 이 화면의 존재를 모르면 그대로 남는다.

## 5. 서식만으로 끝나는 업체의 조건

아래를 **모두** 만족하면 서식을 올리고 `/report-inputs`의 몇 칸만 채우면 된다.

1. 철강 제품(부속서 II 품목)을 만들고, 원료는 사 온 강재다.
2. 연료는 태우는 연료뿐이다(석회석 등 공정배출·물질수지 없음).
3. 공용 연료·전력을 공정별로 재는 계량기가 없다(있으면 전력은 공정별 값을 적을 수 있고, 연료는 화면에서 고쳐야 한다).
4. 자체 보일러의 스팀·온수를 여러 공정이 나눠 쓰지 않는다(쓰면 열량 기준 귀속 — 화면).
5. 밖에서 스팀·온수를 사 오지 않고, 폐가스·자가발전·CO₂ 이전이 없다.
6. 한 공정의 산출물을 다른 공정이 원료로 쓰지 않는다(사내 이송 없음).
7. 한 공정의 여러 제품이 같은 원료를 생산량 비율대로 쓴다.
8. 전력 공급원이 하나다(한전).

하나라도 벗어나면 그 부분은 앱 화면에서 사람이 판단해 넣어야 한다 — 서식은 그 사실을 일부만 알아챈다(밖에서 산 열 「예」, 폐가스 「예」).
