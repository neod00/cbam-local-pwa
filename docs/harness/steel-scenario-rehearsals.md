# 철강 제품 산정 시나리오 리허설

기준일: 2026-07-12

이 문서는 초보자 UI와 기존 산정 엔진을 실제 브라우저 IndexedDB 데이터로 검증한 두 시나리오를 기록한다. 모든 값은 기능 검증용 가정이며 실제 신고값이 아니다.

## 반복 실행

```powershell
npm.cmd run rehearse:steel-product
npm.cmd run rehearse:steel-complex
npm.cmd run verify:calculation
```

각 브라우저 리허설은 별도 Chrome 프로필을 사용하므로 사용자의 로컬 프로젝트를 변경하지 않는다.

## 시나리오 1: 단일 제품·단일 전구물질 경로

- 제품: 열연강판, CN 72083900
- 생산량: 10,000 t
- 전력: 6,000 MWh, 0.466 tCO2e/MWh
- 도시가스: 500,000 Nm3, NCV 0.037 GJ/Nm3, EF 56.1 tCO2e/TJ
- 구매 슬래브: 10,500 t, 직접 SEE 1.35, 간접 SEE 0.25 tCO2e/t

관찰 결과:

- 자체 직접배출: 1,037.85 tCO2e
- 자체 간접배출: 2,796 tCO2e
- 전구물질 직접배출: 14,175 tCO2e
- 전구물질 간접배출: 2,625 tCO2e
- 현재 앱 규칙의 CBAM 기준 배출량: 15,212.85 tCO2e
- CBAM 기준 SEE: 1.521285 tCO2e/t
- 내부 검토용 SEE: 2.063385 tCO2e/t
- Export 차단 오류: 0건

단일 제품에서는 입력, 계산, Annex II 간접배출 제외 설명, 대시보드, 결과, Export 준비 흐름이 일관되게 동작했다.

## 시나리오 2: 공용 공정의 다중 산출물·다중 전구물질 경로

공용 열연 압연공정 산출물:

- 열연강판, CN 72083900, 8,000 t: CBAM 대상 주제품
- 밀스케일, CN 26190090, 200 t: 비CBAM 부산물
- 공정 총 산출량: 8,200 t
- 질량 배분율: 열연강판 97.56098%, 밀스케일 2.43902%

공용 활동자료:

- 전력: 4,500 MWh, 0.466 tCO2e/MWh = 2,097 tCO2e
- 도시가스: 400,000 Nm3 = 직접배출 830.28 tCO2e

전구물질 경로:

- 전기로 슬래브: 5,000 t, 직접 SEE 0.55, 간접 SEE 0.35
  - 직접 2,750 tCO2e, 간접 1,750 tCO2e
- 고로·전로 슬래브: 3,500 t, 직접 SEE 1.85, 간접 SEE 0.18
  - 직접 6,475 tCO2e, 간접 630 tCO2e
- 전구물질 합계: 직접 9,225 tCO2e, 간접 2,380 tCO2e

## 개선 후 재실행 결과

- 공정 자체 배출은 질량비로 배분하고, 두 슬래브 전구물질은 `output_allocations`로 열연강판에만 귀속했다.
- 열연강판 CBAM 기준 배출량: 10,035.0293 tCO2e
- 열연강판 CBAM 기준 SEE: 1.2543787 tCO2e/t (8,000 t 신고 대상 생산량 기준)
- 밀스케일 내부 검토 배출량: 71.3971 tCO2e. `see_cbam_basis`는 `null`이며 상세 화면에는 `해당 없음`으로 표시된다.
- 간소화 결과와 대시보드는 신고 대상만 핵심 지표에 반영하고 밀스케일은 접힌 `배분 참고` 영역으로 분리한다.
- 두 전구물질 생산경로는 IndexedDB와 목록에 각각 표시된다.
- 비CBAM 밀스케일과 그 전용 전구물질은 EU Export에서 제외되며 차단 오류는 0건이다.
- 신규 신고범위·귀속 필드는 `.cbam` 백업에 유지되고 필드가 없는 이전 백업도 그대로 파싱된다.

개선 전 엔진 관찰 결과:

- 두 제품 결과 라인이 생성되고 질량비로 공정 배출과 전구물질 배출이 배분된다.
- 열연강판 결과의 CBAM 기준 배출량: 9,810.0293 tCO2e
- 비CBAM 밀스케일에도 354.4459 tCO2e의 `see_cbam_basis x output` 결과가 생성된다.
- 결과/대시보드에 표시된 합계: 10,164.4751 tCO2e, SEE 1.2395701 tCO2e/t
- 두 전구물질 생산경로는 IndexedDB에 서로 다른 값으로 저장된다.
- 전구물질 목록에는 저장된 생산경로가 표시되지 않는다.
- 비CBAM 밀스케일을 EU goods category로 매핑할 수 없어 Export 차단 오류 1건이 발생한다.

## 개선 전 발견된 문제

### P0: 신고 정확도와 범위

1. **비CBAM 산출물이 CBAM 합계에 포함된다.**
   산정 엔진은 모든 제품 생산라인에 `see_cbam_basis`를 만든다. 대시보드와 결과 화면도 모든 라인을 합산하므로 비CBAM 밀스케일 354.4459 tCO2e가 `CBAM 기준 배출량`에 포함됐다.

2. **배분 대상과 신고 대상을 구분하는 필드가 없다.**
   비CBAM 부산물은 공정 배출 배분의 분모에는 필요하지만 EU 보고 대상에서는 제외되어야 한다. 현재는 삭제하면 배분이 틀어지고, 남기면 결과 합계와 Export를 오염시킨다.

3. **전구물질의 제품별 귀속 규칙이 불명확하다.**
   `PurchasedPrecursor.product_id`가 있어도 엔진은 공정에 연결된 전구물질 전체를 모든 산출라인에 공정 배분율로 나눈다. 특정 슬래브 경로가 특정 제품에만 귀속되는 경우를 표현할 수 없다.

### P1: 데이터 모델과 Export

4. **제품 스키마가 철강 72/73류에 고정돼 있다.**
   `Product.hs_group`이 `72 | 73`만 허용한다. 밀스케일 CN 2619 같은 비CBAM 부산물을 정상 분류할 수 없고 초보자 화면은 73으로 시작하지 않는 모든 CN을 72로 추정한다.

5. **비CBAM 부산물이 Export를 차단한다.**
   제품 목록 전체를 EU goods category로 매핑하므로 배분용 비CBAM 산출물도 오류가 된다. `CBAM 대상`, `비CBAM 공동산출물`, `폐기물/재활용`, `내부소비` 범위가 필요하다.

6. **전구물질 생산경로가 저장되지만 검토 화면에 보이지 않는다.**
   서로 다른 EAF/BF-BOF 경로를 저장할 수 있으나 목록과 간단 화면에서 비교할 수 없다. 공급사, 국가, 생산경로, 소비량, 직접/간접 SEE를 한 행에서 검토해야 한다.

### P2: 초보자 UX와 감사 추적

7. **간단 결과 화면이 제품별 배분을 설명하지 않는다.**
   전체 합계와 구성만 보여서 8,000 t 열연강판과 200 t 밀스케일이 어떻게 배분됐는지 알기 어렵다.

8. **초보자 전구물질 입력이 생산경로를 소비 공정 경로로 복사한다.**
   전구물질 자체의 생산경로를 별도로 묻지 않으므로 여러 공급사·여러 생산경로를 정확히 입력하기 어렵다.

9. **배분 근거의 감사 추적이 부족하다.**
   질량/수동 비율은 저장되지만 왜 해당 기준을 선택했는지, 어떤 산출물은 신고 제외인지, 전구물질이 어느 제품에 귀속되는지 한 화면에서 추적할 수 없다.

## 당시 권장 개선 순서

1. 제품/산출라인에 `reporting_scope`를 추가한다: `CBAM_GOOD`, `NON_CBAM_COPRODUCT`, `WASTE_RECYCLE`, `INTERNAL_ONLY`.
2. 계산 결과를 `allocation result`와 `reportable CBAM result`로 분리하고 비CBAM 결과의 `see_cbam_basis`는 `null` 또는 명시적 `not_applicable`로 처리한다.
3. 전구물질-산출물 귀속 테이블을 추가한다. 전구물질별 대상 생산라인과 귀속 질량/비율을 저장한다.
4. 제품 스키마의 72/73 고정을 제거하고 CN/HS 코드와 CBAM 범위를 독립적으로 관리한다.
5. 결과 화면에 제품별 배분 요약을 추가한다. CBAM 대상 합계와 비CBAM 배분 참고값은 시각적으로 분리한다.
6. 전구물질 화면에 공급사·국가·생산경로·SEE 구성 열을 표시하고 경로별 기여도를 시각화한다.
7. Export는 `CBAM_GOOD`만 내보내되 비CBAM 공동산출물이 배분 분모에 정상 반영됐는지 별도 검증한다.

## 완료 수용 기준

- 비CBAM 공동산출물을 유지해도 Export 차단 오류가 발생하지 않는다.
- 비CBAM 공동산출물은 공정 배분에는 참여하지만 CBAM 총량과 SEE 합계에는 포함되지 않는다.
- 서로 다른 전구물질 생산경로와 제품별 귀속이 입력·목록·결과·백업·복원에 유지된다.
- 결과 화면에서 제품별 배분율, 직접/간접/전구물질 기여, 신고 포함 여부를 확인할 수 있다.
- 단일 제품 시나리오와 복합 시나리오가 모두 자동 회귀 테스트로 통과한다.
- 공식 EU Communication 템플릿을 확보한 뒤 실제 복사본 생성과 Excel 재계산까지 추가 검증한다.
