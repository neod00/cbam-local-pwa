- 2026-10-05: In-plant shared heat (boiler / steam header used by more than one production process) is attributed by heat used, as 2025/2547 Annex III A.3 requires (`CBAM-ALLOC-HEAT-02`). Before, the boiler fuel was split across processes by output mass and booked as DirEm*. Now a fuel stream can carry `heat_system` (no `process_id`) and processes carry `heat_consumption` (quantity, unit, basis: metered / efficiency proxy / indirect estimate with a stated reason). The engine pools the system's fuel emissions E and attributes `E × Qi / Qtot` to each consuming process (Qtot includes heat used outside the production processes, e.g. an office, whose share leaves the CBAM calculation), so consumers + outside = E with nothing omitted or double counted; the share is added to the existing EmH,imp field (`imported_heat_emissions_tco2e`, split out as `shared_heat_emissions_tco2e`). The EU copy writes it into the same D_Processes measurable-heat cells as purchased heat (L+46 = Q in TJ, L+47 = E ÷ Qtot), summed with purchased heat when both exist, and lists the boiler fuel in B_EmInst. The denominator uses ALL processes, not only those in the document. The report states the formula. Backup `format_version` 4 is written only when such data exists, so older apps refuse it instead of dropping the fuel. Also closes an existing hole the release flow exposed: a fuel stream tied to no process and no heat system was silently outside calculation and export, so readiness now blocks it with the amount that would vanish.
