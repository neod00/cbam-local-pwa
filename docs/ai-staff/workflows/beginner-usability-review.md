# Beginner Usability Review

## Purpose

씨봉이를 초보 담당자 역할로 실행해 CBAM Local의 실제 사용 마찰을 찾는다.

## Flow

1. 대표가 테스트할 화면 또는 여정을 정한다.
2. 씨봉이가 가상 회사와 가상 품목으로 앱을 사용한다고 가정한다.
3. 씨봉이는 막힌 화면, 이해 안 된 용어, 다음 행동을 몰랐던 순간을 기록한다.
4. 씨봉이는 개선안을 P0/P1/P2로 나눈다.
5. 씨밤이 또는 Product Impact Analyst가 전문가 판단이 필요한 쟁점을 분리한다.
6. Product / Developer Agent가 코드, 문서, 테스트 작업으로 바꾼다.

## Data Boundary

실제 고객 계산자료, 증빙자료, EU 템플릿 작성본, `.cbam` 백업은 사용하지 않는다. 테스트는 가상 입력과 화면 설명만 사용한다.
