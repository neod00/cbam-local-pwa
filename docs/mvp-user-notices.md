# MVP User Notices

CBAM Local PWA를 무료 배포하기 전에 앱 화면, README, 약관 또는 배포 안내에서 사용자에게 반드시 전달해야 할 고지입니다.

## 필수 고지

- 이 앱은 CBAM 산정과 EU 제출용 파일 준비를 돕는 업무 보조 도구입니다.
- 이 앱은 법률 자문, 관세/세무 자문, 공식 검증기관의 검증, 최종 제출 책임을 대체하지 않습니다.
- 회사의 생산량, 배출량, 전구물질, 공급업체 자료, EU 템플릿 파일은 기본적으로 브라우저 로컬 저장소에서 처리됩니다.
- 브라우저 데이터 삭제, 프로필 초기화, 기기 교체, 회사 보안 프로그램 정리 작업으로 로컬 데이터가 삭제될 수 있습니다.
- 중요한 입력 후에는 반드시 `.cbam` 백업 파일을 내려받아 회사 보안정책에 맞는 위치에 보관해야 합니다.
- EU 제출용 Excel은 사용자가 보유한 최신 공식 원본 템플릿을 업로드해 생성해야 합니다.
- 앱은 공식 원본 템플릿을 직접 수정하지 않고, 입력 가능한 셀에 값을 반영한 복사본을 생성합니다.
- Export 후에는 Excel에서 복사본을 열어 공식 수식 재계산 결과와 앱의 산정 결과를 대조해야 합니다.
- SEFA 및 CBAM 인증서 비용 지표는 검토용 시나리오이며, 이미 납부한 탄소가격 공제는 공식 산식 확인 전까지 반영하지 않습니다.
- 무료 PWA 제공은 소스코드 공개, 재배포 허가, 상업적 호스팅 대행 허가를 의미하지 않습니다.

## MVP 이후로 분리한 고지

- 무료 라이선스 등록, 사용자 연락처 관리, 공지 발송, 관리자 콘솔은 MVP 이후 별도 배포관리 기능으로 검토합니다.
- Docker/on-premise, 다중 사용자, 고객사/프로젝트 관리, 감사 추적, 고급 계산엔진 보호는 향후 유료 또는 고급 버전 후보입니다.
