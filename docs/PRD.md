# PRD — 중소·중견 철강기업용 CBAM 배출량(SEE) 산정 플랫폼 (HS 72·73 중심)

## 1. 제품 목표
### 1.1 목적
- 중소·중견 철강 기업이 EU로 수출하는 CBAM 대상 철강 제품(HS 72류, 73류)의 내재배출(SEE: tCO2e/t)을 산정한다.
- 대외 제출/커뮤니케이션 기능은 제외하고, “내부 산정/검증/재현성 확보”에 집중한다.
- 제품이 대부분 ‘가공품’인 현실을 반영하여, 산정은 기본적으로:
  - (A) 구매한 철강 소재/반제품의 SEE(precursor) + 
  - (B) 자사 가공공정에서 발생한 직접/간접 배출
  - (C) 스크랩/수율(수율은 제품당 배출 집약도에 큰 영향)
  를 합산해 계산한다.

### 1.2 주요 사용자(중소·중견 현실)
- 환경/ESG 담당(비전문가 가능), 생산기술/공무, 품질/영업 지원
- IT 전담 인력이 없어도 템플릿 업로드로 운영 가능해야 함

## 2. 대상 제품 범위(HS 기준)
### 2.1 HS 72류(기초 가공 제품/중간재)
- 판재류: 7208, 7209, 7210, 7211 등 (열연/냉연 판재, 코일, 시트)
- 봉강 및 형강: 7213, 7214, 7215 등 (봉, 막대, 앵글, 채널 등)
- 선재/와이어: 7217 (철선, 스프링/와이어 제품 원료)

### 2.2 HS 73류(완성 구조물/부속품)
- 파이프 및 튜브: 7303, 7304, 7305, 7306
- 철강 구조물: 7308
- 탱크/저장용기: 7309, 7310
- 철도용품: 7302
- 나사/볼트/너트: 7318
- 기타 주조/단조/가공품: 7326

## 3. 제품화 컨셉(중소·중견 맞춤)
### 3.1 산정 모델(현실형)
- “정밀 공정 모델”이 아니라 “실무형 합산 모델”:
  - 제품 SEE = (자사 가공 배출 / 제품 출하량) + Σ(precursor SEE × 질량비)
- precursor는 보통 대기업/외부에서 구매한 소재(열연코일, 빌렛, 봉강, 강판 등)이며,
  - 공급사가 제공한 SEE를 입력하거나
  - 기본값(내부 정책)을 사용할 수 있게 한다(정책/버전으로 관리).

### 3.2 핵심 품질장치(내부 신뢰성)
- 입력 검증(누락/단위/이상치/수율)
- 산정 재현성(입력 스냅샷 + EF 버전 + 규칙 버전)
- 기여도(전력/연료/precursor 상위 항목)

## 4. 핵심 사용자 여정
1) 설비(Installation) 등록(경계/전력계/연료계 여부)
2) 제품 등록(HS 코드 + 제품군 템플릿 선택)
3) 기간(12개월 기본) 생성
4) precursor(구매재) 입력(SEE + 질량비/BOM)
5) 활동자료 업로드(전력/연료/생산량/스크랩/수율)
6) 계산 실행 → 결과(Direct/Indirect/Precursor/Total) 확인
7) 내부 보고용 Export(엑셀/CSV) 생성

## 5. 핵심 기능 범위(Modules)
- M01 설치/설비(Installation) 및 경계
- M02 제품(HS72/73 분류) 및 공정 타입(템플릿)
- M03 기간(Reporting Period) 관리(12개월 기본)
- M04 precursor/BOM(질량비) 입력(내부/외부)
- M05 활동자료 업로드/검증(템플릿 기반)
- M06 배출계수(EF) 관리(전력/연료, 버전)
- M07 산정 엔진(Direct/Indirect + Precursor + 수율)
- M08 결과/기여도/검증 리포트 + Export

## 6. 범위/우선순위(MVP)
### MVP(반드시)
- HS72/73 제품군 템플릿 + 엑셀 업로드
- precursor/BOM(질량비) 1~2단계
- 전력(Indirect) 중심 + 연료(Direct) 선택
- 수율(투입 vs 출하) 반영
- 결과표(제품별 SEE) + 기여도 Top5 + 경고
- 결과/근거 버전 고정(재현성)

### Phase 2(선택)
- 공정별 세분(압연/도금/용접/열처리/절삭/단조/주조)
- 증빙 업로드(전력 EF 실제값 등)
- ERP/계측 연동 API
