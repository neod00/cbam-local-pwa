# Design System Inspired by Apple

> 출처: getdesign.md 계열 분석(사용자 제공). CBAM_Platform `/scenarios` Apple 트라이얼(design/scenarios-apple-trial)의 참조.
> 요약: 밝은 여백형 · 단일 블루 액센트(#0066cc) · 근검은 잉크(#1d1d1f) · 그림자 거의 없음 · 밝은/다크 타일 교차.

## 핵심
- 사진 우선, UI는 물러남. 장식(테두리·그라디언트·그림자) 최소. **카드 그림자 없음** — 유일한 드롭섀도(rgba(0,0,0,0.22) 3px 5px 30px)는 제품 이미지에만.
- 표면: 흰색 `#ffffff`, 파치먼트 `#f5f5f7`(시그니처 오프화이트), 펄 `#fafafc`, 다크 타일 `#272729/#2a2a2c/#252527`, 순수 검정 `#000`(글로벌 내비만). **밝은 타일 ↔ 다크 타일 교차 자체가 섹션 구분선**.
- 텍스트: `#1d1d1f`(순수 검정 아닌 근검정) 헤드라인·본문. 다크 위 흰색, 보조 `#cccccc`.
- **단일 블루 액센트 `#0066cc`** — 모든 인터랙티브(링크·pill CTA·포커스). 두 번째 브랜드색 없음. 다크 위 링크는 `#2997ff`.
- 타이포: SF Pro Display/Text. 대체 **Inter + ss03** + 디스플레이 음수 자간. 웨이트 **300/400/600/700(500 없음)**. 헤드라인 600, 본문 **17px/400/1.47/-0.374px**(16px 아님). 300은 airy 순간에만 드물게.
- 라운드: pill(9999) = 블루 CTA·검색·칩; 유틸 카드 18px; 다크 유틸 버튼 8px; 펄 11px; 풀블리드 타일 0.
- 버튼 active = `transform: scale(0.95)`.

## CBAM_Platform 적용 매핑(트라이얼)
- 밝은 페이지 + 파치먼트 타일 교차. **그림자 없음, 헤어라인만**. 결론은 다크 히어로 대신 **밝은 여백형 큰 타이트 숫자**(museum 느낌).
- 인터랙티브·링크·CTA = 블루 #0066cc(단일). 숫자 = 근검정.
- 유리/주의는 애플식 절제로 아주 옅은 그린/오렌지 pill(환경 페이지의 subtle green 선례). 큰 색 대비 지양.
- 폰트 Inter(SF 대체) + ss03, 본문 17px, 디스플레이 600 + 음수 자간.

(전체 원문은 대화 로그의 사용자 제공 DESIGN.md 참조. 팀 표준 승격 시 이 파일을 정본으로 확장.)
