# v0.1.0-beta Operator Review Packet

Status: OPERATOR_REVIEW_REQUIRED

이 문서는 `CBAM Local v0.1.0-beta` 제한 배포 전 운영자가 마지막으로 확인할 항목을 한 곳에 모은 검토 패킷이다. 코드 검증과 배포 리허설은 완료되었지만, 무료 약관과 공지 문구는 최종 운영/법무 검토 전까지 승인된 것으로 보지 않는다.

- 배포 URL: `https://cbam-local-pwa.vercel.app/`
- 검토 기준: GitHub `main`의 최신 Vercel 배포본
- 기술 검증: 통과
- 배포 리허설: 통과
- 릴리스 상태: 약관/공지 검토 전까지 `NOT READY`

`/terms` 페이지는 공개 URL에서 볼 수 있게 추가했지만, 현재 문구는 검토용 초안이다. 최종 공개 전에는 아래 항목을 승인해야 한다.

## 운영자 승인 필요 항목

- 서비스명: `CBAM Local` 그대로 사용할지 확정
- 운영자명 또는 회사명: 공개 여부와 표기 방식 확정
- 문의 채널: `openbrain.main@gmail.com` 사용 확정
- 보안 문의 채널: `openbrain.main@gmail.com` 사용 확정
- 개인정보 처리 안내: 무료 라이선스 등록을 시작하기 전 별도 고지가 필요한지 판단
- 약관/책임 제한 문구: 법무 또는 운영 책임자 검토
- 무료 배포 공지문: 공개 채널, 대상, 문구 확정
- 베타 대상 범위: 제한 배포인지 공개 링크 배포인지 확정

## Go 조건

아래 항목이 모두 충족되면 `v0.1.0-beta` 제한 배포를 진행할 수 있다.

- `docs/free-pwa-terms-draft.md`의 `LEGAL_REVIEW_REQUIRED` 상태가 승인 상태로 변경됨
- `docs/free-pwa-release-announcement-draft.md`의 `OPERATOR_REVIEW_REQUIRED` 상태가 승인 상태로 변경됨
- `/terms` 페이지 문구가 승인된 약관/고지와 일치함
- 공지문에 로컬 우선, 최신 EU 원본 템플릿 직접 업로드, `.cbam` 백업, Excel 재계산 확인, 공식 검증 대체 아님이 포함됨
- `npm.cmd run release:status`가 남은 blocker를 표시하지 않음

## No-Go 조건

아래 항목 중 하나라도 남으면 배포 공지를 보류한다.

- 약관/책임 제한 문구가 승인되지 않음
- 운영자 또는 문의 채널이 확정되지 않음
- 사용자가 CBAM 계산 데이터가 서버에 저장된다고 오해할 수 있는 문구가 남아 있음
- 사용자가 앱 결과만으로 EU 제출이 완료된다고 오해할 수 있는 문구가 남아 있음
- Export 후 Microsoft Excel 공식 수식 재계산 확인 절차가 공지에서 빠짐
- 실제 회사 자료, EU 템플릿 원본, `.cbam` 백업 파일을 공개 채널에 첨부하도록 유도하는 문구가 남아 있음

## 권장 첫 공지문

아래 문구를 기준으로 배포 채널에 맞게 다듬는다.

```text
CBAM Local PWA 무료 베타를 제한 배포합니다.

이 앱은 CBAM 대상 기업 담당자가 품목, 생산공정, 배출원 자료, 전구물질, SEE 및 SEFA/인증서 시나리오를 브라우저 로컬 환경에서 정리하고, 최신 EU 원본 Communication template 기반 Export 복사본을 준비할 수 있도록 만든 업무 보조 도구입니다.

입력 데이터, EU 템플릿, .cbam 백업 파일은 기본적으로 운영 서버로 전송하지 않고 브라우저 안에서 처리됩니다. 다만 브라우저 데이터 삭제나 PC 교체에 대비해 중요한 변경 후에는 .cbam 백업을 별도로 보관해야 합니다.

Export 후에는 반드시 Microsoft Excel에서 공식 수식 재계산 결과를 확인하세요. 이 앱은 법률 자문, 공식 검증, 회사 내부 승인, 최종 EU 제출 책임을 대체하지 않습니다.

앱: https://cbam-local-pwa.vercel.app/
약관/고지: https://cbam-local-pwa.vercel.app/terms
문의: openbrain.main@gmail.com
```
