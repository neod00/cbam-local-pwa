# 컨설턴트용 사용 안내 — 활동자료 서식에서 EU 문서까지

업체를 방문해 자료를 받는 사람(컨설턴트)과 그 자료를 앱에 올려 EU 문서를 만드는 사람을 위한 순서다. 앱은 철강 제품만 산정하며, 한 프로젝트는 **한 해 · 한 사업장** 단위다. 앱은 모든 값을 브라우저 안에서만 처리한다(서버로 보내지 않는다).

## 1. 준비 — 서식 받기

1. 앱의 **자료 업로드** 화면 → 「활동자료 서식 내려받기」 → **빈 서식 내려받기**. (예전 4시트 서식도 그대로 올릴 수 있다.)
2. 서식에는 「(예시)」로 시작하는 줄이 있다. 보기이며 지우지 않아도 올릴 때 건너뛴다.
3. 노란 칸에만 적는다. 진한 초록 머리글(* 표시)은 꼭 적을 칸, 회색은 아는 경우에만. 모든 양은 **보고기간(보통 1년) 합계**다.

## 2. 업체에 묻고 받을 것 (시트별)

| 시트 | 받을 자료 | 자주 틀리는 것 |
|---|---|---|
| 1_사업장 | 공장·법인 영문명/주소, 사업자번호, 담당자, 보고기간, 한전 전기 사용량(고지서 12개월 합계), 전력 배출계수 | 전력량은 **MWh**(kWh를 1,000으로 나눈다). 계수는 2025/2621 부속서 II 표의 값 + 출처를 적는다 |
| 2_제품 또는 2b_품번목록 | EU로 나가는 품번·CN 8자리·강종·연간 생산량(t)·불량·스크랩 | CN은 수출신고필증으로 확인. 「강도구분 8.8」은 인장강도 800 MPa 이상 구분 CN이다(앱이 알려 준다). 같은 CN은 강종이 달라도 한 제품이다 |
| 3_공정 | 생산 라인과 생산량 | 품번 목록을 쓰면 앱이 만든다 |
| 4_연료 | 도시가스·LPG·경유 등 연간 사용량과 고지서 | 가열로·열처리로처럼 일부 제품만 거치는 설비는 「공장 전체」가 아니라 그 공정 이름을 적는다. 전기도금·절단·용접·마무리 전용 연료는 적지 않는다(용융아연도금·코팅은 적는다) |
| 5_구매강재 | 사 온 선재·봉강의 CN·투입량·공급사·나라, 공급사가 준 배출량 값과 검증 여부 | **제조 공장의 나라**(무역상 말고). 공급사 값에 제3자 검증보고서가 없으면 앱이 기본값을 쓴다 |
| 13_외주공정 | 열처리·코팅을 외주사에 맡겼다 돌려받으면 외주처 연료 중 우리 몫 | 돌아온 부품은 5_구매강재에 적지 않는다(이중계산). 몫을 정하는 방법 4가지는 서식 설명 줄에 있다 |
| 6·7 | 역할·책임, 증빙 목록 | 아는 만큼 |
| 8~12 | 해당할 때만: 사 온 열, 보일러 열, 공정배출, 사내 이송, 전력 공급원 | |

모를 때는 칸을 비워 둔다. 올리면 앱이 「확인할 것」으로 알려 준다.

## 3. 앱에 올리기

1. 지도 화면의 **새 프로젝트**로 시작한다(처음 한 업체의 자료를 넣을 때). 확인창이 두 번 뜬다.
2. **자료 업로드 → 채운 활동자료 서식 올리기**.
3. 품번 목록에 강종 구성이 다른 CN이 있으면 **「한 공정으로 합침 / CN별 공정으로 나눔」** 카드가 뜬다. 카드의 표(합치면·나누면 값)와 「합쳐지는 이유」를 보고 고른다. 차이가 작으면 합침이 단순하다. 저탄소 원료를 쓴 제품을 따로 보여야 하면 나눔. 고른 방식은 모니터링 계획에 적고 해마다 같게 적용한다.
4. 결과 화면의 **확인할 것**(넣지 못함 · 확인 필요 · 참고)을 위에서부터 본다. **「목록 복사」**로 서식을 채운 분께 그대로 보낼 수 있다.
5. 고친 서식을 같은 프로젝트에 다시 올릴 때는 **바꿔 넣기**를 고른다(지금 자료를 `.cbam`으로 내려받은 뒤 지우고 새로 채운다).

## 4. 8단계까지

- **산정 지도 / 대화**에서 빠진 입력을 채운다. **할 일** 화면은 누가 할 일인지(우리 회사·공급사·규정상 확인)로 모아 보여 준다.
- **제출** 화면의 점검표가 「보낼 수 있습니다」인지 본다. 오류만 파일 만들기를 막고, 나머지는 「기본값」「잠정」으로 적혀 나가므로 수입업자가 물을 수 있다.
- **내려받기**: EU Communication 엑셀 · 산정 보고서(Word) · 모니터링 계획 초안(Word) · 전달 패키지(zip, 위 셋 + 점검표 + 백업).

## 5. 내려받은 뒤 반드시

1. **EU 엑셀을 Excel에서 한 번 열어 공식 수식이 다시 계산됐는지 본다.** 앱은 입력 셀에만 값을 넣고 공식은 건드리지 않는다.
2. **모니터링 계획 초안**은 「초안 — 회사 확인·승인 필요」다. 「작성 필요」로 남은 항목(측정기 위치·검교정·위험 평가 등)은 회사가 적는다.
3. 프로젝트를 **`.cbam`으로 저장**해 둔다(파일 메뉴 → 저장). 다음 해는 새 프로젝트로 시작한다.

## 6. 앱이 하지 않는 것

- 제3자 **검증**을 대신하지 않는다. 검증을 받을 수 있는 수준의 산정과 근거 정리까지 돕는다.
- 법률 자문, 회사 내부 승인, 최종 제출 책임을 대체하지 않는다.
- 철강 외 품목, 사업장이 여럿인 한 프로젝트는 지원하지 않는다(사업장마다 프로젝트를 따로 만든다). 외주처의 전기는 **국내(같은 나라 전력망) 외주처만** 받는다 — 해외 외주처의 전기는 검증인과 처리 방식을 따로 정한다.
- 실제 회사 자료·EU 템플릿 원본·`.cbam` 백업을 공개 채널에 올리지 않는다.
