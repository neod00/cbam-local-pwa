# MVP Rehearsal Plan

이 문서는 CBAM Local PWA를 무료 배포하기 전, 기업 담당자 관점에서 처음부터 제출 준비까지 실제로 따라가며 확인하는 리허설 절차다.

## Goal

- 사용자가 무엇을 먼저 해야 하는지 막히지 않는지 확인한다.
- 로컬 저장, 기준자료 업로드, 계산, 시나리오, EU Export, `.cbam` 백업 흐름이 끊기지 않는지 확인한다.
- 앱이 법률 자문, 공식 검증, 최종 제출 책임을 대체하지 않는다는 고지가 필요한 위치에 보이는지 확인한다.

## Test Persona

- 국내 중소·중견 제조기업 CBAM 담당자
- Excel은 사용할 수 있지만 CBAM 산정 구조에는 익숙하지 않은 사용자
- 회사 생산량, 연료, 전력, 전구물질 자료를 외부 서버에 올리는 것을 꺼리는 사용자

## Required Local Files

리허설 파일은 Git에 넣지 않는다.

- 최신 EU `CBAM Communication template for installations` 원본 Excel
- 최신 또는 테스트용 `CBAMBenchmarks_*.xlsx`
- 최신 또는 테스트용 `DVsasadopted_*.xlsx`
- 리허설용 가상 회사 입력값: [docs/mvp-fictional-dataset.md](mvp-fictional-dataset.md)

## Local File Verification Commands

공식/기준자료 파일은 저장소에 커밋하지 않고, 로컬 파일 경로를 넘겨 검증한다.

```bash
npm run verify:local-eu-template -- "<path-to-CBAM-Communication-template.xlsx>"
npm run verify:local-references -- "<path-to-CBAMBenchmarks.xlsx>" "<path-to-DVsasadopted.xlsx>"
```

`verify:local-eu-template`은 EU 원본 템플릿의 시트, CN 행, 계획된 쓰기 셀, 공식 수식 보존 여부를 확인한다.

`verify:local-references`는 벤치마크와 국가/CN 기본값 파일을 앱의 로컬 파서로 읽고, 행 수, CN 코드 수, 국가 시트, 샘플 조회 가능 여부를 확인한다.

## Rehearsal Flow

1. 앱 첫 화면 확인
   - Dashboard에서 다음 작업이 명확히 보이는지 확인한다.
   - 로컬 우선, Export, 백업 안내가 과도하게 숨겨져 있지 않은지 확인한다.

2. 사업장 등록
   - 사업장명과 국가 코드만으로 저장되는지 확인한다.
   - 주소, 담당자 정보가 선택 항목으로 보이는지 확인한다.

3. 보고기간 등록
   - 분기 또는 테스트 기간을 만들고 상태가 이해되는지 확인한다.

4. 품목 등록
   - CN 8자리 코드, 제품명, 품목군을 입력한다.
   - CN 코드 누락 또는 검색 결과 없음 안내가 실무자에게 이해되는지 확인한다.

5. 생산공정 등록
   - 공정 기본정보, 제품 생산라인 배분, 생산량과 배출량을 순서대로 입력한다.
   - 한 공정에서 여러 제품이 나오는 경우 배분율 검토 메시지가 보이는지 확인한다.

6. 배출원 자료 등록
   - 생산공정에 연료 또는 공정 원료 배출원을 연결한다.
   - 활동자료, 배출계수, 출처를 입력하고 예상 배출량이 보이는지 확인한다.

7. 전구물질 등록
   - 공급사 실제자료 또는 공식 기본값 사용 케이스를 각각 입력한다.
   - 기본값 사용 사유, 검증 상태, 출처 누락 경고가 보이는지 확인한다.

8. 기준자료 업로드
   - 벤치마크와 국가/CN 기본값 파일을 가져온다.
   - 서버 전송 없음, 로컬 저장 안내가 명확한지 확인한다.

9. 산정 결과 확인
   - 제품별 직접 SEE, 간접 SEE, 총 SEE가 표시되는지 확인한다.
   - 모바일에서는 카드 형태로 핵심 숫자가 읽히는지 확인한다.

10. SEFA 및 인증서 시나리오 확인
    - 기준값 연결, 실측/기본값 SEE 비교, 인증서 비용 지표를 확인한다.
    - 검토용 시나리오이며 탄소가격 공제는 아직 공식 산식 확인 전이라는 안내가 보이는지 확인한다.

11. EU Export 준비
    - 최신 EU 원본 템플릿을 업로드한다.
    - Export 차단 오류와 경고가 수정 화면으로 연결되는지 확인한다.
    - `Summary_Products` 공식 수식 셀은 덮어쓰지 않는다는 안내가 보이는지 확인한다.

12. 제출용 복사본 생성
    - 복사본 파일이 다운로드되는지 확인한다.
    - Microsoft Excel에서 복사본을 열어 공식 수식 재계산 결과를 확인한다.
    - 앱의 SEE 검토값과 Excel 재계산 결과를 비교한다.

13. `.cbam` 백업
    - 설정 화면에서 백업 파일을 내보낸다.
    - 백업 파일을 다시 가져와 미리보기 건수와 시나리오 가정값이 보이는지 확인한다.
    - 복원 전 현재 로컬 데이터가 교체된다는 경고가 이해되는지 확인한다.

## Pass Criteria

- 사용자가 Dashboard에서 다음 작업을 찾을 수 있다.
- 필수 입력과 선택/검토 항목이 구분된다.
- 모든 민감 입력값은 브라우저 로컬 또는 사용자가 내려받은 파일에만 남는다.
- Export 전 오류와 경고가 수정 화면으로 연결된다.
- 제출용 Excel 복사본 생성 후 공식 수식 재계산을 수동 확인한다.
- `.cbam` 백업 내보내기와 가져오기 경고가 명확하다.

## Known MVP Limits To Confirm

- 내부 활동자료 일괄 업로드와 수집 템플릿 다운로드는 MVP 이후 기능이다.
- 무료 라이선스는 현재 로컬 mock이며, 계산 기능을 막지 않는다.
- 관리자 콘솔과 원격 라이선스 API는 MVP 이후 별도 구현이다.
- PWA JavaScript 번들은 사용자가 열람할 수 있으므로 고급 보호 로직은 향후 서버/API 또는 Docker/on-prem 버전으로 분리한다.
